## 本题讲解：国际经济机构促进全球化——功劳簿与天花板

答案：**BCD**。

### 第 0 步：先立机制——这些机构靠什么起作用

二战后国际垄断资本建立 IMF（管国际收支与汇率）、世界银行（管长期资金）、WTO（管贸易规则）等机构，本质是为各国垄断资本的协调与制约提供**制度化平台**，作用通道有三条：**立规则**（贸易规则、汇率安排、贷款条件）、**搭平台**（谈判与争端解决）、**给协调**（政策协商）。

通道决定“表现”的样子：规则降低了跨境交易成本 → **贸易扩张**；平台把各国绑进同一套制度 → **联系加强**；协调便利了要素跨境 → **资本、技术等流动加快**。三件看得见的事，就是经济全球化“促进”的落点——B、C、D。

### 第 1 步：预判追问——“表现”和“能力”有什么区别，A 为什么错

设问问的是“促进全球化发展的**表现**”，A 答的是“**有效应对**全球性经济波动和经济危机”。表现 = 它确实推动了什么（贸易、联系、要素流动，量的扩张与联系的密度）；治理能力 = 它能否消除系统性危机的根源。

这些机构建立在**垄断资本利益协调**之上，协调再顺畅也**触及不到资本主义基本矛盾**——危机的根源未除，“有效应对”无从谈起，2008 年国际金融危机就是反例。促进开放合作 ≠ 能治理危机，A 是把“功劳簿”拔高成了“治理书”。

### 第 2 步：A~D 对号入座

| 选项 | 判定 | 归因 |
|---|---|---|
| A 有效应对全球性经济波动和经济危机 | ✗ | 拔高性绝对化表述：超出机构的制度能力，消除不了基本矛盾 |
| B 推动了商品和服务贸易的迅速增加 | ✓ | 立规则、降成本的直接结果——表现一 |
| C 加强了各国和各经济体之间的联系 | ✓ | 制度化协调合作的直接结果——表现二 |
| D 加快了资本和技术等要素的国际流动 | ✓ | 投资贸易便利化的直接结果——表现三 |

### 易错点

- **误选 A**：把“促进全球化发展”顺理成章推成“还能应对危机”——混淆“表现”与“治理能力”；且“有效应对”这种绝对化字眼在政治选择题里多为陷阱信号。
- **漏选 B/D**：只盯住题干里“协调”“制约”的字眼，往抽象原理上想；忘记贸易扩大、要素流动才是全球化最直观的表现。

> 记忆锚点：国际经济机构的全球化功劳簿 = 贸易增（B）· 联系密（C）· 要素流动快（D）；危机应对是它的**制度天花板**（A 错）——协调触及不到资本主义基本矛盾。
