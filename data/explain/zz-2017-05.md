## 本题讲解：过渡时期五种经济成分——个体经济的过渡形式是合作社经济

答案：**C（合作社经济）**。

### 第 0 步：先立机制——过渡时期的社会是一张"成分 × 去向"的网

从新中国成立到 1956 年社会主义改造完成，我国既不是纯粹的社会主义社会，也还留着旧社会的成分——**五种经济成分并存**。命题考"谁向谁过渡"，考的就是这张网。先把坐标立起来：

| 经济成分 | 性质 | 在改造中的位置 |
|---|---|---|
| 社会主义性质的国营经济 | 全民所有 | 领导力量，是各条改造线的**终点形态**本身 |
| 半社会主义性质的合作社经济 | 劳动者集体占有与私有并存 | **个体经济 → 社会主义集体经济的过渡形式** |
| 农民和手工业者的个体经济 | 劳动者私有 | 改造对象（起点） |
| 私人资本主义经济 | 资本主义私有 | 改造对象（起点） |
| 国家资本主义经济 | 在人民政府管理之下的资本主义 | **私人资本主义 → 国营经济的过渡形式** |

有了坐标，再记两条改造路线（起点 → 过渡形式 → 终点）：

1. **个体经济**（农业、手工业）：互助组 → 初级社 → 高级社，走**合作化**道路，过渡形式 = **合作社经济**；
2. **私人资本主义**：加工订货 → 个别企业公私合营 → 全行业公私合营，走**国家资本主义**道路，过渡形式 = 国家资本主义经济。

题眼问"**个体经济**向社会主义**集体经济**过渡的形式"——在第一条路线上对号入座，就是**合作社经济**，选 **C**。

### 第 1 步：预判追问——为什么 A、D 都沾"大词"却不对

- **为什么国营经济（A）不是过渡形式？** 国营经济本身就是社会主义性质，是改造要到达的**目标形态**，又是整个国民经济的领导力量——它站在终点上，不需要再"向社会主义过渡"。说国营经济是过渡形式，等于说终点是通往终点的那座桥。
- **为什么国家资本主义（D）不能选？** D 确实是"过渡形式"，但它是**另一条路线**上的桥：接的是私人资本主义，通向国营经济。题眼把起点限定为"个体经济"——起点不同，桥就不同。命题人把 D 放在这里，专考"两条路线不要串线"。
- **合作社为什么叫"半社会主义"？** 初级社里土地入股、统一经营，社员既有私有的土地分红，又有集体积累——私有因素与社会主义因素并存，所以是"半"社会主义；到高级社土地归集体，才完全公有化。这种"一半旧一半新"的形态，恰好说明它是过渡的桥。

### 第 2 步：干扰项归因

| 选项 | 错在哪 | 对应的误解 |
|---|---|---|
| A | 社会主义性质的领导力量，是目标不是桥 | 把"终点"当成"过渡形式" |
| B | 本身是被改造对象，属资本主义改造那条线 | 看见"资本主义"四个字就忘了题眼限定"个体" |
| D | 过渡形式没错，但接的是私人资本主义那条线 | 只认"过渡"两个字、不核对起点——最强干扰项 |

### 易错点

- 最容易选 D："过渡形式"四个字对了就冲上去——必须再核对**起点**：个体经济的桥是合作社，不是国家资本主义。
- 两条路线别串线：**农业/手工业（个体）→ 合作社；资本主义工商业 → 国家资本主义**。

> 记忆锚点：个体经济 → **合作社经济**（半社会主义性质）；私人资本主义 → **国家资本主义**；国营经济是领导力量和终点形态，不是过渡形式。
