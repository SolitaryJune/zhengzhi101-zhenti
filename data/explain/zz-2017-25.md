## 本题讲解：给“第一动力”找全依据——两源、一定位、两落点

答案：**ACD**。

### 第 0 步：先立机制——重大论断考的是“依据链”，不是背一句口号

做题先立模型：题干给了一个重大定位——创新是**引领发展的第一动力**（十八届五中全会提出新发展理念时摆在首位的那个“创新”），然后问“把创新作为第一动力”**是**什么。这类定位题考的从来不是口号本身，而是它的**来龙去脉**：一个论断凭什么立起来（来源），立起来之后落到哪里去（落点）。本题四个选项恰好摆成一条链：

**两个来源（D）→ 一个定位（第一动力）→ 两个落点（A、C）**

先看来源端。2016 年 5 月党中央、国务院颁布《国家创新驱动发展战略纲要》，把创新作为第一动力写进国家战略——写进战略的论断必有支撑，支撑来自两条：

- **历史依据——看世界**：近现代世界发展历程反复证明，每次科技革命（蒸汽机、电力、信息技术）都重排国家实力版图；谁站上创新前沿，谁就握住发展制高点，国际竞争的实质已聚焦**科技创新能力**；
- **实践依据——看自己**：总结改革开放以来的实践，我国从要素驱动、投资规模驱动走向创新驱动；经济进入**新常态**后速度换挡、结构优化，背后正是**动力转换**。

再看落点端。定位立起来要交两份答卷：对**国际**竞争，创新是提高核心竞争力的必然选择（A）；对**国内**发展，创新是引领经济发展新常态的根本之策（C）。D 说的“分析世界发展历程和总结我们改革开放实践得出的结论”，正是来源端的**原文**——链条的起点。

### 第 1 步：预判“为什么”——B 为什么接不上这条链

判干扰项最可靠的办法是**领域对表**。“构建和谐世界”是 2005 年提出的中国**外交理念**，管的是国际秩序、对外关系；“第一动力”讲的是**国内发展动力**。链条的每一环——历史依据、实践依据、两个落点——全部落在“发展”领域内，B 属于“外交”领域：接不上来路，也对不上落点。记住：**表述本身正确的句子，不等于本题该选的选项**——它必须在这条链条上占一个位置才行。

### 第 2 步：四个选项对号入座

| 选项 | 在依据链上的位置 | 判定 |
|---|---|---|
| A 提高核心竞争力的必然选择 | 落点·国际（竞争实质 = 科技创新能力） | ✅ |
| B 构建和谐世界的内在要求 | 外交领域，接不上任何一环 | ❌ |
| C 引领经济发展新常态的根本之策 | 落点·国内（新常态 = 动力转换） | ✅ |
| D 分析世界发展历程和总结改革开放实践得出的结论 | 来源·原文（历史依据 + 实践依据） | ✅ |

→ 来源（D）→ 定位 → 落点（A、C），选 **ACD**。

### 易错点：每个漏项/误项对应哪种误解

- **误选 B**：被“内在要求”这类万能句式带偏——凡看到“必然选择”“内在要求”就心动时，先做领域对表：和谐世界 = 外交，第一动力 = 发展，领域不接，直接排除。
- **漏选 D**：只背“第一动力”的定位、不问它从哪来。重大论断教材必交代**得出的依据**（世界经验 + 中国实践），D 是这句话的原文表述，漏掉等于丢了链条的起点。
- **漏选 C**：新常态与创新之间断在“动力转换”一环。补上链条：新常态 → 速度换挡 → 要素驱动减弱 → **动力转换 → 创新驱动 = 根本之策**。
- **漏选 A**：把“第一动力”只当国内政策，忘了国际竞争聚焦科技创新——创新上不去，核心竞争力无从谈起。

> 记忆锚点：依据链 = **来源（D：世界历程 + 改革开放实践）→ 定位（第一动力）→ 落点（A 核心竞争力 + C 新常态根本之策）**；“和谐世界”（B）是外交理念，领域不接，不选。
