## 本题讲解：垄断定价的两条线——低于成本价格才叫净亏损

答案：**A（成本价格）**。

### 第 0 步：先立机制——三个价格概念摆上桌

垄断组织靠**垄断价格**获利：卖货用**垄断高价**（价值以上卖出），进货用**垄断低价**（价值以下买进），两头夹出**垄断利润**。要把"最低能接受什么价"问清楚，先摆出三个价格台阶：

| 价格 | 构成 | 含义 |
|---|---|---|
| **成本价格** | c + v（垫付的不变资本 + 可变资本） | 收回本钱的线 |
| **生产价格** | 成本价格 + 平均利润 | 自由竞争阶段利润率平均化后的"正常利润线" |
| **垄断价格** | 成本价格 + 垄断利润 | 垄断组织"想卖"的价位 |

### 第 1 步：数值推演——价格被压到哪一条线才算"净亏损"

设垫付成本 c + v = 100，平均利润 = 20，垄断利润 = 50，则成本价格 = 100、生产价格 = 120、垄断价格 = 150。市场交易中获利高低受竞争、供需等因素影响，卖价可能被从 150 一路压下来：

| 卖价 | 处境 | 判断 |
|---|---|---|
| 150 | 赚足垄断利润 | 最理想 |
| 130 | 低于垄断价、高于生产价格 | 照样赚 |
| 110 | 低于生产价格（平均利润拿不满） | **少赚，不亏**——本钱 100 已收回 |
| 95 | 低于成本价格 | **净亏损**——连本钱都收不回 |

分界清清楚楚：卖价只要 ≥ 100，成本已补偿，至多少赚；卖价 < 100，垫付的 c + v 都收不回，才叫**净亏损**。所以"避免净亏损"的最低可接受价 = **成本价格**。

### 第 2 步：预判追问——为什么"低于生产价格"不算亏？

这是本题最大的陷阱。生产价格 = 成本价格 + **平均利润**，平均利润是自由竞争阶段资本家按资本量分得的"正常份额"。低于平均利润只是**赚得比"正常份额"少**，本钱并没有折损——少赚 ≠ 亏损。两条线的位置关系：生产价格 = 成本价格 + 平均利润 > 成本价格，**生死线永远在正常利润线下面**。把"低于平均利润"误当成"亏损"，就会掉进 B。

### 第 3 步：逐项对号入座

| 选项 | 判断 | 理由 |
|---|---|---|
| A 成本价格 | ✅ | c + v 的补偿线；低于它才净亏损，是"最低可接受价" |
| B 生产价格 | ❌ | 正常利润线；低于它但高于成本价只是少赚 |
| C 垄断低价 | ❌ | 垄断组织**买进**时压价的手段，不是卖出时的底线 |
| D 垄断高价 | ❌ | 垄断组织**卖出**时抬价的手段，与"最低接受价"方向相反 |

### 易错点：每个干扰项对应哪种误解

- **误选 B**：混淆"利润为零的界线"（成本价格）与"利润低于平均水平的界线"（生产价格）。把自由竞争阶段的平均利润当成垄断阶段"不亏"的前提——实际垄断组织获利"高低受很多因素影响"，跌破平均利润完全可能也完全可以接受。
- **误选 C / 误选 D**：把"获利**手段**"当"价格**底线**"。垄断低价是进货时把买价压到价值以下、垄断高价是出货时把卖价抬到价值以上，都是"往有利方向使劲"的手段；题目问的是"最低能接受什么"，问的是底线，不是手段。
- **概念回退**：还有人用"平均利润率下降""竞争失败"等枝节解释，忘了题眼只在"避免**净亏损**"四个字——净亏损的定义就是收不回成本价格。

> 记忆锚点：两条线——**成本价格 = 生死线（c + v，低于它才净亏损）**，生产价格 = 正常利润线（低于它只是少赚）；垄断高价/低价是**手段**，成本价格是**底线**——手段与底线分开记。
