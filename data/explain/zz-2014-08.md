## 本题讲解：建设社会主义文化强国，「关键」定位在哪一环

答案：**C（增强全民族文化创造活力）**。

### 第 0 步：先立模型——「文化强国」是一套有分工的表述体系

这道题属于**定位题**：题干不问「什么是重要的」，而问「其**关键**是」。文化强国建设的配套表述在教材里各挂一个位置，先把这张定位表立起来：

| 定位 | 内容 | 对应选项 |
|---|---|---|
| **关键** | 增强全民族文化创造活力 | C |
| 根本任务 | 培育「四有」公民，提高全民族思想道德素质和科学文化素质 | B |
| 目标/标志 | 提高国家文化软实力 | D |
| 具体举措 | 发展文化事业和文化产业、发展新型文化业态等 | A |

为什么「关键」落在创造活力上？机制是这样的：文化创造**的主体是全体人民**，一个民族文化能不能强起来，最终取决于这个民族有没有旺盛的**创造活力**——活力是发动机、是发动的杠杆；有了它，国民素质的提升、软实力的增强、新业态的繁荣才有源头。其余各项都是活力发挥出来的**结果**或**载体**。所以「关键」= **增强全民族文化创造活力**，选 C。

### 第 1 步：干扰项逐个过筛——都是「重要」，但都不在「关键」这个位置

- **A「发展新型文化业态」**：文化产业层面的**具体举措**，是做事情的抓手之一，层次低于「关键」；把抓手当关键，是把「手段」提到了「杠杆」的位置。
- **B「提高全民族思想道德素质和科学文化素质」**：表述在教材里真实存在，但挂在**根本任务**名下（培育「四有」公民的落脚点）。定位题考的就是**挂对位置**——内容对、位置不对，照样不选。
- **D「提高国家文化软实力」**：最像答案的干扰项。软实力是建设文化强国的**目标追求与标志**——「强起来」之后呈现出来的结果；用第 0 步的机制说：先有创造活力这个发动机，才谈得上软实力这个输出。把「结果」当「关键」，因果就倒置了。

### 第 2 步：预判追问——「目标」和「关键」怎么区分才不出错

B、D 都「真的重要」，都出现在文化强国的话语体系里，凭什么只选 C？区分的办法是问一句：这一项是**发动的杠杆**，还是**预期的结果**？

- 创造活力：先有它，才有后续的一切 → 杠杆 → 关键；
- 素质提升（B）：是活力作用于人的结果，也是根本任务要完成的指标 → 结果；
- 软实力（D）：文化「强起来」在国际上的呈现 → 结果；
- 新业态（A）：让活力落地变现的产业形式 → 载体/举措。

题干问「关键」，就是问「发动机在哪」——四选一里只有 C 是发动机。

### 易错点

- **误选 D（看到「强国」就选「软实力」）**：字面联想的典型——「文化强国↔文化软实力」词面最贴，但题干问的是「其**关键是**」，软实力处于「目标」层。
- **误选 B（把根本任务当关键）**：B 的表述教材里确实有，靠「眼熟」做题就会掉进去；定位题必须核对它挂在哪个定位之下。
- **漏看题眼**：本题属于「关键/根本/目标/核心/保证」定位词系列题，审题第一步先把定位词圈出来，再回忆对应的定位表。

> 记忆锚点：文化强国定位表——**关键=增强全民族文化创造活力**；根本任务=培育「四有」公民（B）；目标=文化软实力（D）；业态=举措（A）。问「关键」，选「活力」这个发动机。
