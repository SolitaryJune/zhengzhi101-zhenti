## 本题讲解："有用 + 劳动产品"还差什么才是商品——差交换

答案：**ABD**。

### 第 0 步：先立机制——商品判定要过三关

马克思这句话本身就是判据：一个物可以**有用**、可以是**人类劳动产品**，但**不是商品**。商品 = 用于**交换**的劳动产品，于是判定流程三关：

| 关卡 | 问的问题 | 卡在这关的物 |
|---|---|---|
| 第一关：有用性 | 能满足人的需要吗 | 空气、阳光（非劳动产品也卡在这之后） |
| 第二关：劳动产品 | 是人类劳动创造的吗 | —— |
| 第三关：交换 | 进入市场、所有权相互让渡了吗 | **自用的、缴纳的、馈赠的** |

题干问"符合'一个物（不是商品）'的"——就是**过了前两关、卡在第三关**的物。判断的焦点全在"有没有交换"上。

### 第 1 步：四个选项过三关

- **A 中世纪农民为封建主生产作为代役租的粮食**：有用 ✅、劳动产品 ✅、但作为代役租**交给**封建主——依附关系下的强制缴纳，不进入市场交换 ❌ → **不是商品，选**。马克思在《资本论》里正以此例说明劳动产品不一定是商品。
- **B 农民为养活家人生产并消费的农副产品**：有用 ✅、劳动产品 ✅、自产自用直接消费，无交换 ❌ → **不是商品，选**。
- **C 农业资本家为获取利润而生产的农产品**：为**利润**而生产，必然要到市场上**出卖**才能实现利润——三关全过 → **是商品**，不符合"不是商品"，**不选**。
- **D 封建社会时期由佃农生产并上缴给地主的地租（实物地租）**：有用 ✅、劳动产品 ✅、上缴地主——同样是封建剥削关系内的直接缴纳，不经交换 ❌ → **不是商品，选**。

### 第 2 步：预判追问——为什么"缴租"不算交换

有人会问：粮食从佃农手里转到地主手里，所有权变了，怎么不算交换？关键在**交换的定义**：商品交换是产品在**平等主体之间**的相互让渡，受价值规律（等价交换）支配。而地租（代役租、实物地租）是**超经济强制**下的缴纳——依附关系的产物，不是等价交换，价值规律在这里不登场。产品**转移**了，但没有**交换**。

### 第 3 步：为什么 C 必须排除

C 是反向陷阱：资本主义农业生产的**目的就是利润**，而利润只能在市场上实现——农产品必然作为商品出卖。如果 C 不出卖，就没有利润可言，资本主义生产本身就不成立。所以 C 不仅"是商品"，还是题干语境里最典型的商品。

### 易错点

- **误选 C**：以为"利润"与"商品"无关，或把"获取利润"误读成不通过市场。实际上利润的实现**以交换为前提**。
- **漏选 A/D**：被"转移占有"迷惑，以为缴租也算"交易"。区分"缴纳/转移"与"等价交换"：后者才是商品的出场方式。
- **漏选 B**：想当然认为农民生产的东西都是商品。自给自足正是"劳动产品不是商品"的教科书案例。

> 记忆锚点：商品判定三关卡——**有用、劳动产品、用于交换**；差第三关的：自用（B）、缴租（A/D）都不是商品；为利润而产（C）必入市场，是商品。
