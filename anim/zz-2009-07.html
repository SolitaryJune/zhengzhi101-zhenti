本题讲解：涨价动的是哪种「资本构成」

答案：B（资本价值构成）。

第 0 步：先立模型——三种构成的定义链

政治经济学里「资本构成」有三个概念，考的就是把它们分开：

概念定义由什么决定
资本技术构成生产资料数量与劳动力数量的比例（实物层面）生产技术水平
资本价值构成不变资本 c 与可变资本 v 的比例（价值层面）技术构成 + 生产要素价格
资本有机构成由技术构成决定并反映技术构成变化的价值构成技术进步

注意价值构成的「双因性」：它既随技术构成变（机器多了 c 变大），也随价格变（原料涨价 c 同样变大）。

第 1 步：判别口诀——先问「技术动没动」

  1. 铁矿石价格上涨：钢铁厂所用的矿石吨数、工人人数等实物比例并没有变 → 技术构成不变；
  2. 但矿石贵了，投在原材料上的不变资本 c 增大，c : v 的价值比例改变 → 价值构成变了；
  3. 有机构成的门槛是「由技术构成决定并反映技术构成变化」——本题没有技术变化，所以这次价值构成的变化不构成有机构成的变化。

第 2 步：对号入座

选项判断理由
A 资本技术构成❌实物数量比例没动，只动了价格
B 资本价值构成✅c 增大，c:v 价值比例改变
C 资本物质构成❌不是政治经济学规范概念，凑数项
D 资本有机构成❌缺「技术构成变化」这一前提

易错点

  • 直接选 D（惯性跳坑）：见到「资本构成变化」就联想「有机构成」——判别关键是先问一句「技术变了吗」；本题只是涨价，有机构成的定义链条接不上。
  • 选 A（把价格当实物）：涨价改变了「值多少钱」，不改变「用多少东西」。
记忆锚点：技术构成看实物，价值构成看钱（c:v）；有机构成=技术引起的那部分价值构成变化。价格动→只动价值构成。
