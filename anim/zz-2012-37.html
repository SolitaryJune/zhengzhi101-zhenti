本题讲解：信义兄弟——诚信的道德力量与法律关系中的诚实信用

答题要点：第(1)问按"是什么—为什么重要—材料怎么体现"三层答：诚信是诚实劳动、信守承诺、真诚待人，是立身处世之本、市场经济正常运行之基，道德力量表现为以实际行动承担责任 → 建立信任 → 形成道德感召；第(2)问落到法律层面：诚实信用是民事活动的基本原则，行使权利、履行义务都要讲诚信，它保障交易安全与合理信赖、降低社会交往成本、维护正常秩序。

第 0 步：先立机制——"良心账"为什么反而算得准

材料最耐人寻味的细节：账单找不到，凭一本"良心账"，工友们说多少就给多少，33.6 万元竟与哥哥遇难前哥俩说过的数额相差无几。这不是玄学：20 年不欠薪的信用记录，意味着双方对工钱数目彼此心里有数——诚信在长期交往中沉淀为共同预期，所以"良心账"能对上账。这个细节要答出两层：诚信既是内在德性（不欺人、不欺心），也是交往理性（它让复杂的社会合作低成本、可预期）。第(1)问的"道德力量"从这里展开；第(2)问把镜头从道德拉到法律：工资支付是劳动法律关系中的义务，权利的行使与义务的履行同样以诚信为基础。

第 (1) 问：怎样理解诚信及其道德力量（6 分）

层次原理材料对应
诚信是什么诚实劳动、信守承诺、真诚待人；中华民族传统美德，公民道德建设的重点"新年不欠旧年账，今生不欠来生债"；20 年从未拖欠工资
对个人：立身之本"人无信不立"，诚信是为人之道、立足之本，人格独立的标志"诚信，是为人之道，也是立足之本"
对社会：经济运行之基市场经济本质上是信用经济，诚信是经济社会正常运行的基本要求工程款拿不到也四处借钱按时发薪——宁可自己受困，先保承诺
道德力量如何显现以行动承担责任 → 建立信任 → 形成感召、引领风尚母亲拿出 1 万元养老钱；69 名工友说"明年我们跟你接着干"

收口：道德力量不是抽象说教，而是由一贯的诚信行为积累出的信任与感召力——信义兄弟用行动证明"信"能凝聚人心、带动他人。

预判追问："先发工钱再办丧事"是不是不近人情？ 恰是采分点：这说明诚信已内化为道德信念和人格追求，不是权衡利弊后的策略选择。道德力量之所以打动人，正来源于这种非功利性——它在最艰难的处境下依然成立。

第 (2) 问：在法律关系中，为什么也要坚守诚信（4 分）

  • 原理：诚实信用是民事活动应当遵循的基本原则（被称为"帝王条款"）：行使权利、履行义务应当遵循诚信原则，信守约定。法律关系中的权利义务既有法律强制力保障，也以当事人之间的合理信赖为基础。
  • 为什么：①保障交易安全与合理信赖——对方基于承诺安排生产生活，背信即损害信赖利益；②降低社会交往成本——普遍诚信使合作不必事事设防；③维护正常的经济秩序——工资支付、合同履行都以信用为纽带。
  • 对应材料：孙东林与农民工之间是劳动（劳务）法律关系，按时足额支付工资是法定义务；兄遭变故仍代兄清偿，是把法律义务的履行升华为道德自觉——法律是底线，诚信让底线之上更有温度。

易错点

  • 第(1)问只复述事迹不提炼：事迹是论据，得分点是"诚信的内涵 + 个人、经济、社会三个层面 + 行动→信任→感召的机制"，堆故事不给分。
  • 第(2)问只背概念不答"为什么"：要落到交易安全、合理信赖、降低成本、维护秩序，并回扣"工资支付是法律关系中的义务"这一材料事实。
  • 道德法律两张皮：好的答案会点出二者贯通——诚信既是道德要求，也是法律原则，材料正是"法律义务 + 道德自觉"的叠加。
记忆锚点：诚信三层 = 立身之本 + 信用经济之基 + 社会有序之要；道德力量 = 行动担责 → 建立信任 → 形成感召；法律诚信 = 行使权利、履行义务都讲信用——保障安全、降低成本、维护秩序。
