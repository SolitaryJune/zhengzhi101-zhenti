本题讲解：从"一物降一物"到"创新之路越走越宽"——唯物辩证法答题框架

答题要点：问(1)考唯物辩证法——矛盾的同一性和斗争性、事物间的普遍联系、认识和利用固有联系改变条件促成平衡（和谐不是没有矛盾）；问(2)考实践与认识的辩证运动（创新从实践的真实问题出发）、突破僵化思维（辩证法的批判革命精神/辩证否定观）、正确理论指导实践并在检验修正中相互促进。

第 0 步：先立机制——材料里藏着什么哲学结构

把材料翻译成哲学语言：水花生（泛滥方）与叶甲（制约方）构成一对矛盾。叶甲"专食性，只吃水花生"是矛盾双方斗争性的表现——一物降一物，相互制约；而"一物降一物"的平衡法则之所以成立，是因为害虫与天敌同处一个生态系统、相互依存——这是矛盾双方的同一性。生态系统中生物之间"水花生—叶甲—农作物—水域环境"的牵一发而动全身，则是普遍联系的直观图景。生物防治没有消灭矛盾，而是认识和利用事物固有的联系，改变条件（引进天敌），把失衡的旧平衡调成不损害农作物的新平衡。

第(1)问："一物降一物"平衡法则的三层原理（先原理，后材料对应）

  • 矛盾观点：害虫与天敌既对立又相互制约——斗争性是"降"（相互排斥、相互制约），同一性是平衡（双方相互依存、共处于一个统一体中）；斗争性寓于同一性之中，平衡正是矛盾双方又斗争又统一的状态。
  • 普遍联系观点：联系具有客观性、普遍性、多样性——生态系统是相互联系的有机整体（水花生泛滥 → 水质恶化 → 鱼蟹死亡 → 传播寄生虫，一条联系链）；生物防治不是臆造联系，而是认识和利用既有联系来改变条件。
  • 落点——平衡与和谐：生物防治通过利用天敌制约害虫，形成新的相对平衡；注意不能把和谐理解为没有矛盾——和谐是矛盾双方协调共处的状态，不是矛盾的消失。

第(2)问：为什么"跳出传统思维模式，创新之路会越走越宽"

  • 创新从实践的真实问题出发：物理防治成本高且加剧蔓延、化学防治带来次生污染——实践中的难题倒逼人们寻找新方法；实践是认识发展的动力，正是实践中暴露的矛盾推动认识突破旧框架。
  • 突破僵化思维是前提："防治病虫害必须用化学农药"是僵化的思维定式。辩证法在对现存事物的肯定理解中同时包含否定的理解，按其本质来说是批判的、革命的——跳出定式才能探索新联系、新方法（引进叶甲、捕食螨）。
  • 实践与认识在循环中相互促进：新认识（生物防治）指导新实践（每年 4—5 亿亩次、"十三五"绿色防控率 40% 以上），实践又检验和修正认识——实践推动理论创新，正确理论指导实践，二者在持续检验与修正中螺旋上升，所以创新之路"越走越宽"。

预判"为什么"：为什么引进叶甲不算"人为制造混乱"

因为叶甲的专食性是水花生与叶甲之间固有的客观联系，农业技术人员是经实地调研后发现并利用它，而不是凭空制造联系。尊重联系的客观性与发挥主观能动性在这里统一：能动性体现在"找到、引进、投放"的实践过程，规律性体现在"只吃水花生"的自然属性——这正是普遍联系原理中"利用联系改变条件"的本意。

易错点

  • 问(1)只答"联系"漏"矛盾"或反之：材料"一物降一物"同时体现斗争性制约与普遍联系，两层都要答，且都要接材料（叶甲专食性、水花生泛滥链）。
  • 问(1)把平衡说成"没有矛盾"：和谐是矛盾双方的协调状态，不是矛盾的消失——这是参考答案点名的辨析点。
  • 问(2)只背"创新很重要"不答机制：必须落到实践倒逼认识与突破僵化思维两个机制上，并用材料举证（物理/化学防治失灵 → 生物防治 → 绿色防控率目标）。
  • 问(2)漏"正确理论指导实践"：只答"实践出认识"是半个循环——新认识还要回去指导更大规模的实践，"越走越宽"说的是这个不断放大的循环。
记忆锚点：一物降一物 = 斗争性制约 + 固有联系；平衡 = 矛盾双方的协调态，不是无矛盾；创新 = 实践真实问题倒逼 + 跳出僵化思维 + 理论指导实践循环放大。
