本题讲解：两大理论成果"一脉相承"的脉在哪里

答案：AC。

第 0 步：先立机制——"相承"承什么，得先分清不变量与变量

毛泽东思想与中国特色社会主义理论体系，是马克思主义中国化（把马克思主义基本原理同中国具体实际相结合）的两大理论成果。判断"一脉相承"的方法不是逐句找相同字眼，而是先问：从革命年代走到改革开放，哪些东西换不了、哪些东西必然换？

  • 换不了的（不变量）：一是世界观和方法论的根——都以马克思主义基本原理为理论基础；二是贯穿始终的精髓——实事求是，一切从实际出发。无论革命还是建设，这条"认路的方法"不能丢，这正是"脉"的源头与魂。
  • 必然换的（变量）：时代在变（战争与革命 → 和平与发展），任务也在变（革命、改造 → 建设与改革）。成果要"与时俱进"，恰恰体现在变量上。

所以"一脉相承"承的是魂（原理 + 精髓），"与时俱进"变的是叶（任务 + 时代）。题问"一脉相承"，就去找不变量。

第 1 步：A–D 对号入座

选项属于不变量还是变量判定
A 马克思主义的理论基础不变量：两成果同出一源✅
C 实事求是的理论精髓不变量：活的灵魂贯穿始终✅
B 革命和建设的根本任务变量：两段历史任务各不相同❌
D 和平与发展的时代背景变量：时代判断恰恰不同❌

→ 承的是原理与精髓，选 AC。

易错点：B、D 各对应一种典型误解

  • 误选 B（把后来才有的任务倒灌回共同点）：毛泽东思想创立时根本没有"建设中国特色社会主义"的任务——任务清单是两段历史各自开出来的，属于"与时俱进"的部分，不是"一脉相承"的部分。
  • 误选 D（把时代差异冒充时代共性）："和平与发展是时代主题"是改革开放以后对时代的判断；毛泽东思想形成于战争与革命年代。D 恰是两大成果的差异项，方向完全反了。
记忆锚点：脉 = 马克思主义原理（A）+ 实事求是精髓（C）；任务（B）会换、时代（D）会变——承魂不承清单。
