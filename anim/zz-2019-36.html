本题讲解：马克思列宁主义为什么是"全新选择"与"三次伟大飞跃"说明了什么

答题要点：问(1)用"排除 + 对比"作答——旧方案逐一破产说明旧路走不通，马克思列宁主义的科学性说明新路为何走得通，"新"必须相对"旧"而言；问(2)用时间轴把"站起来—富起来—强起来"对上三个历史时期，落点是历史和人民的选择与马克思主义中国化。

第 0 步：先立机制——近代中国的两大历史任务与"方案竞争"

1840 年鸦片战争后，中华民族面临两大历史任务：争得民族独立和人民解放；实现国家富强和人民幸福。要理解什么叫"指明了前进方向、提供了全新选择"，先看清"旧选择"为什么全部失败——近代以来的救国方案是一场以实践为裁判的方案竞争：

  • 旧式农民战争（太平天国）走到尽头——农民阶级不代表新的生产方式，提不出科学的纲领；
  • 不触动封建根基的自强运动和改良主义（洋务运动、戊戌变法）屡屡碰壁——只在器物、制度表层修补，不敢动封建根基；
  • 资产阶级革命派领导的革命（辛亥革命）和其他资本主义方案纷纷破产——民族资产阶级的软弱性，没有科学理论、没有发动最广大的工农，改变不了半殖民地半封建的社会性质。

竞争的胜负标准是实践：谁能科学地认识中国、组织起最广大的力量、指明符合规律的道路。

第(1)问：如何理解马克思列宁主义给中国人民"指明了前进方向，提供了全新选择"（5 分）

  • "新"在性质：十月革命一声炮响送来的马克思列宁主义，不是又一种救国"方案"，而是科学的世界观和方法论——它揭示了人类社会发展的一般规律，给先进分子提供了观察国家命运、认识中国社会的思想武器（分析工具，而非现成药方）。
  • 对比旧方案：旧方案失败在缺乏科学理论指导；马克思主义第一次把社会主义从空想变成科学，指明了经过新民主主义走向社会主义的前进方向——这就是"前进方向"与"全新选择"的实质。
  • 与工人运动结合：马克思列宁主义同中国工人运动相结合，中国共产党应运而生——中国革命从此有了坚强的领导核心、科学的指导思想和崭新的奋斗目标。
  • "结合"才是成功的机制：中国共产党人把马克思列宁主义基本原理同中国革命和建设的具体实际结合起来，完成新民主主义革命和社会主义革命，建立中华人民共和国和社会主义基本制度——实现中华民族从东亚病夫到站起来的伟大飞跃。照搬本本并不行（教条主义曾使革命遭受严重挫折），结合才有胜利。

第(2)问：三次伟大飞跃说明了什么（5 分）

  • 时间轴对齐：三次飞跃对应三个历史时期——新民主主义革命和社会主义革命（东亚病夫 → 站起来）；改革开放（站起来 → 富起来）；中国特色社会主义新时代（迎来从富起来到强起来的伟大飞跃）。
  • 说明了历史和人民的选择经得起实践检验：选择了马克思主义、选择了中国共产党、选择了社会主义道路——每一个选择都被随之而来的伟大成就所证实。
  • 说明了马克思主义必须中国化：毛泽东思想指导站起来，中国特色社会主义理论体系指导富起来、强起来——基本原理同具体实际结合，才有理论与实践的良性互动。
  • 说明了道路的正确性与世界意义：只有社会主义才能救中国，只有中国特色社会主义才能发展中国；科学社会主义在二十一世纪的中国焕发出强大生机活力，拓展了发展中国家走向现代化的途径，为解决人类问题贡献了中国智慧和中国方案。

易错点

  • 问(1)只说"马克思主义科学"、不对照旧方案：设问是"全新选择"——"新"是相对旧方案的失败而言，必须先列方案破产清单再讲科学性，这是答题的完整链条。
  • 问(1)漏掉"与中国实际结合"：成功机制不是"照搬俄国经验"，而是基本原理同中国具体实际相结合；漏掉这一层就答成了"本本万能"。
  • 问(2)只背"三次飞跃"、不答"说明了什么"：飞跃是现象，设问要的是结论——历史选择 + 理论创新 + 道路自信 + 世界意义，四层缺一即不完整。
  • 问(2)时期与飞跃错位："站起来"对应新民主主义革命和社会主义革命（含建设时期的探索），不是改革开放；"富起来"对应改革开放——张冠李戴是最典型的硬伤。
记忆锚点：全新选择 = 旧方案全部破产（农民战争 · 自强改良 · 资产阶级革命）× 科学世界观和方法论（认识工具）× 同工人运动结合建党 × 同具体实际结合制胜；三次飞跃 = 站起来（革命 + 建设）→ 富起来（改革开放）→ 强起来（新时代），背后 = 历史和人民的四个选择 + 马克思主义中国化的理论指导。
