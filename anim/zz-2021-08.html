本题讲解：「从 0 到 1」的突破指向哪一档创新

答案：C（提升原始创新能力）。

第 0 步：机制先行——先立「创新谱系」，再把题眼放到刻度上

创新按成果来源分三档，先立谱系再做题：

档位走向含义
原始创新0 → 1从无到有，产出前所未有的首创性、原理性成果
集成创新1 ＋ 1 → 体系把已有的多项技术整合成新方案
引进消化吸收再创新1 → N在引进学习别人的基础上再改进创造

题眼「从 0 到 1」不是修辞：从零到一＝从无到有，在谱系上正好落在原始创新这一档。习近平在科学家座谈会上的讲话原文正是「要把原始创新能力提升摆在更加突出的位置」。选项 C 与题眼同档、与原文对上，答案直接成立。

第 1 步：预判「为什么现在强调 0 到 1」

我国过去的技术进步大量走「引进—消化—模仿—追赶」的 1 → N 路线；但关键核心技术要不来、买不来、讨不来，「卡脖子」环节无法靠引进解决，只能自己从源头做出来。所以越往科技强国走，越要把力气从「跟跑改进」转到「源头突破」——这就是讲话把原始创新摆在更加突出位置的现实逻辑，也是题眼与选项 C 之间的必然联系。

第 2 步：逐项裁定

  • C 提升原始创新能力 ✅：与「从 0 到 1」同档，且是讲话原文的定点搭配。
  • B 加快推进引进消化吸收再创新 ❌：方向恰好相反——1 → N 是「站在别人成果上」的创新，恰恰不是 0 → 1。这是本题最典型的反向干扰项：考的就是「从 0 到 1」与「引进再创新」的区分。
  • A 强化企业创新主体地位 ❌：层次错位——它回答的是「谁来创新」（企业是创新主体），题问的是「哪一类创新摆在突出位置」；且企业创新大量属应用导向，不特指 0 → 1。
  • D 改善科技创新生态 ❌：泛化归因——生态是外围保障（环境、评价、激励），重要但不回答「哪一类创新」。

易错点

  • 误选 B：只看「创新」二字不看走向——「引进消化吸收再创新」同样是国家支持的创新路径，但走向是 1 → N，与题眼正相反。
  • 误选 A：把「主体」当成「重点」——「企业是创新主体」与「原始创新能力摆在突出位置」是两个考点，前者答主体、后者答类型。
  • 误选 D：凡措施类表述（改善生态、健全机制）都在答「怎么保障创新」，答不了「什么类型的创新」。
记忆锚点：0 → 1＝原始创新（从无到有）；1 → N＝引进消化吸收再创新；「谁来创新」＝企业主体；「生态」＝保障措施——题眼是走向，就按谱系对号。
