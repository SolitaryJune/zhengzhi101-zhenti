本题讲解：基层民主——"直接"的边界在哪里

答案：ABD。

第 0 步：先立机制——我国民主的两个层次

判断"直接"类选项，先把大框架立起来：我国的民主实践分两个层次，每个层次"直接"到哪一步是不同的——

层次载体群众怎么参与
国家层面人民代表大会制度间接：选出人大代表，由代表管理国家事务
基层层面城乡基层政权机关、企事业单位、基层自治组织直接：依法直接行使民主权利，直接管理基层公共事务和公益事业

基层民主在这张图上的定位：它是社会主义民主最广泛、最直接的实践，是发展社会主义民主的基础性工程。"基础性"三个字说清了它的分量——量大面广、人人可及，但它的作用半径画在"基层"圈内。

第 1 步：预判一个"为什么"——为什么不能"直接参与国家事务"？

有人会问：基层群众不也是国家的主人吗，为什么不能直接管理国家事务？——正因为是主人，才更要分清两条参与途径：管理国家事务的法定途径是人民代表大会制度（间接民主），群众经选举把权力委托给人大代表去行使；基层自治管理的是本社区、本单位的公共事务和公益事业。两条线并行不悖，但不能互相替代：如果群众都去"直接管国家事务"，人大制度就被架空了。所以凡是把"直接"接到"国家事务"上的选项，都是层次越界——本题唯一错误项 C 正好踩在这条红线上。

第 2 步：逐项对号入座

  • A 对：发展基层民主，有利于提高全民的素养，为进一步发展民主创造条件——民主素养只能在民主实践中养成：群众在民主选举、民主决策、民主管理、民主监督的直接演练里学会民主的运行规则。（本站选项表述为"民族素养"，通行真题版本作"民主素养"，属印行差异；无论哪种字眼，考点一致——基层民主实践本身就是全民的民主训练，A 入选。）
  • B 对：是发展社会主义民主的基础性工程——教材对基层民主的定性表述，与第 0 步的定位吻合。
  • C 错："为基层群众直接参与国家事务的管理提供了更多机会"——越界。群众直接管理的是基层公共事务和公益事业；管理国家事务走人大间接途径。C 把两个层次焊在了一起。
  • D 对：为基层群众管理基层公共事务和公益事业创造了条件——这正是基层民主的本职，与题干原文吻合。

易错点：干扰项对应哪种误解

  • 误选 C → "越直接越民主"的直觉：把民主的广泛性、直接性当成可以无限扩张的许可证，"直接"两个字一出现就加分。判断口诀：看"直接"后面接什么——接"基层公共事务和公益事业"对，接"国家事务"错。
记忆锚点：基层民主＝基础性工程（B）＋直接管理基层公共事务和公益事业（D）＋在实践中提高素养（A）；"直接"止步于基层，国家事务由人大间接管理（C 错在层次越界）。
