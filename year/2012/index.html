zz-2012-01

感性认识与理性认识
1 分

恩格斯说：“鹰比人看得远得多，但是人的眼睛识别的东西远胜于鹰。狗比人具有锐敏得多的嗅觉，但是它连被人当作各种物的特定标志的不同气味的百分之一也辨别不出来。”人的感官的识别能力高于动物，除了人脑及感官发育得更完美之外，还因为：

答案

答案：A

1

本题讲解：人的感官为何能「识别」——感觉之上还有思维

答案：A（人不仅有感觉还有思维）。

第 0 步：先立机制——认识分两层，「识别」是哪一层的活

认识论把认识分成两个层次，来源和对象都不同：

层次靠什么把握什么
感性认识眼、耳、鼻等感官的直接感知事物的现象、外部联系
理性认识思维（概念、判断、推理）事物的本质、内部联系、规律

再看题眼那个词——恩格斯说人的眼睛能「识别」东西、能辨别被人当作「物的特定标志」的气味。把气味当成某个物的标志、进而指认「这是什么」，已经不是单纯的感觉，而是给感觉材料起名字、归类、建立联系——这是概念、判断的活，是理性认识在加工感性材料。动物停在「感觉到」为止，人能走到「识别出」，差别就在感觉之上多了一层思维。

第 1 步：读题干的两处限定——它替你排除了两个方向

  1. 恩格斯先退一步：论看远鹰胜人、论嗅觉狗胜人——单项感官机能动物占优。所以题目比的不是感官灵敏度本身，比的是感官「之上的」能力；
  2. 题干明写「除了人脑及感官发育得更完美之外」——生理基础这条已被题干自己划掉，问的是「还因为」什么。

两条限定一夹，答案只剩一个落点：感官收到的材料能被思维加工成概念和规律。这正是选项 A。

第 2 步：逐项判定

选项判断理由
A 人不仅有感觉还有思维✅思维=理性认识，「识别」能力正是感觉材料被思维加工的产物
B 人不仅有理性还有非理性❌情感、意志等非理性因素不承担「把气味识别为物的标志」的加工任务，答非所问
C 人不仅有直觉还有想象❌直觉、想象同属非理性因素，与「识别」机制对不上号
D 人不仅有生理机能还有心理活动❌心理活动动物同样具有（趋利避害、情绪反应），分不出人与动物的高下

易错点

  • 选 B/C（觉得「非理性」也显得高级）：把「理性认识」与「非理性因素」混为一谈——题干问的是「识别能力高于动物」的根据，识别=在感觉基础上把握本质与联系，只有思维做得到；非理性因素在此没有岗位。
  • 选 D：「人有心理活动」人畜共有，动物训化后的条件反应就是心理层面的活动，构不成区分。
  • 误以为在比感官：题干先承认单项感官人输给鹰狗，恰是要把答案引向感官之外的层面——顺着感官比永远比不过。
记忆锚点：动物=只有感觉；人=感觉＋思维。感觉负责收料，思维负责识别——把感觉上升为概念、把个别上升为一般，人才胜过鹰眼狗鼻。

zz-2012-02

量变质变规律
1 分

有这样一道数学题：“90%×90%×90%×90%×90%=？”其答案是约59%。90分看似一个非常不错的成绩，然而，在一项环环相扣连续不断的工作中，如果每个环节都打点折扣，最终得出的成绩就是不及格。这里蕴含的辩证法道理是：

答案

答案：B

2

本题讲解：90%×90%×…≈59%——量的积累越过关节点引发质变

答案：B（量变引起质变）。

第 0 步：先立机制——量变、度、质变是一根链条

范畴含义
量变数量的增减、程度的改动，尚未改变事物的性质
度保持事物性质不变的幅度与范围，两端是关节点
质变量的积累突破关节点，事物性质发生根本变化

原理链条：量变是质变的必要准备，质变是量变的必然结果；量积累到一定程度、越过「度」的边界，性质就翻转。所以拿到本题先找三样东西：什么在积累（量变）、边界在哪（度/关节点）、翻成了什么（质变）。

第 1 步：把算式翻译成「量的积累」——连乘推演

连乘次数计算累计成绩与 60 分关节点比
190%×190%度内，仍是好成绩
290%×90%81%度内
3×90%72.9%度内
4×90%≈65.6%度内，但已逼近
5×90%≈59%跌破 60 分——不及格

单看每一个环节，90% 都在「好成绩」这个度的范围之内；但「环环相扣、连续不断」的工作是连乘——每环节的小折扣不断积累，第 5 次乘完累计约 59%，跌破 60 分这个关节点，「好成绩」变成「不及格」：性质翻转了。小折扣（量变）→ 连乘积累 → 破度（质变），正是量变引起质变的日常版本；它同时给出方法论：做事要重视环节质量、掌握适度原则，勿以折扣小而轻之。

第 2 步：逐项判定

选项判断理由
A 肯定中包含否定❌这是辩证否定观的内容，讲事物因内部否定因素而自我扬弃；题干只有数量折扣的积累，没有否定因素的展开过程
B 量变引起质变✅环节折扣连乘积累，成绩由「优」翻成「不及格」，性质变了
C 必然性通过偶然性开辟道路❌题干不涉及必然与偶然的关系，纯数量推演
D 可能和现实是相互转化的❌题干不是可能性与现实性的转化，成绩下降是现实的积累过程

易错点

  • 觉得「每个 90% 都还行」就不算变质：单看一个环节确实在度内——错在忽略连乘的积累效应；量变分析要看总量与趋势，这正是命题设下的陷阱。
  • 选 A（否定之否定最「辩证」）：把「含否定因素的自我运动」套到算式上——题干全程是数量增减与程度变化，没有内部肯定/否定因素的对立展开，属原理错配。
记忆锚点：连乘见质变——90% 的五次方≈59%；环节都打折扣，积累越过关节点（60 分），性质就翻转。

zz-2012-03

资本主义工资
1 分

在资本主义社会里，资本家雇佣工人进行劳动并支付相应的工资。资本主义工资本质是：

答案

答案：B

3

本题讲解：资本主义工资——「劳动的报酬」的假象，劳动力价值或价格的本质

答案：B（工人劳动力的价值或价格）。

第 0 步：先立机制——「劳动」不是商品，「劳动力」才是

这道题的全部密码在一字之差：劳动 ≠ 劳动力。资本家在劳动力市场上买到的，是工人的劳动力（人的劳动能力）在一定时间内的使用权，而不是工人的劳动。为什么劳动本身不能是商品？两条推理就能锁死：

  1. 按价值等价交换 → 资本家付了全部劳动创造的价值，剩余价值无从产生，资本主义制度的地基塌了；
  2. 按不等价交换 → 又直接推翻价值规律。两头都说不通，唯一出路是：被买卖的是劳动力。

再看「劳动力」这件商品的价值由什么决定：和其他商品一样，由生产和再生产它所需要的社会必要劳动时间决定——即维持工人生存、延续工人后代（家庭费用）、培训工人技能（教育训练费用）所需的生活资料的价值。而劳动力这种商品的使用价值很特殊：对它的使用（劳动）能创造出比它自身价值更大的价值——这个差额就是剩余价值，剥削的秘密全在这里。

第 1 步：工资形式如何制造假象

工资表现为「干多少活、拿多少钱」，好像付的是全部劳动的报酬。实际上工资偿付的只是必要劳动那一部分（相当于劳动力价值）；剩余劳动创造的价值被资本家无偿占有。现象（全部劳动的报酬）≠ 本质（劳动力的价值或价格）。

预判追问：为什么资本主义偏偏用「工资」这种形式来付钱？ 按「干了多少活」计酬，恰好把必要劳动与剩余劳动的划分遮住了——整个劳动日看起来都被支付了，剥削关系被形式隐藏。这正是「工资是劳动力价值或价格的转化形式」的含义：本质没变，但穿上了一件掩盖本质的外衣。

第 2 步：对号入座

选项判断理由
A 工人所获得的资本家的预付资本❌预付可变资本是资本家账本上的支出，描述的是资本家的垫付动作，不是「工资」这个范畴的质的规定
B 工人劳动力的价值或价格✅工资是劳动力价值（价格）的转化形式；工人所得≈维持劳动力所需生活资料的价值
C 工人所创造的剩余价值的一部分❌剩余价值恰是工人拿不到、被资本家无偿占有的部分；若工资里含剩余价值，剥削就不成立了
D 工人全部劳动的报酬❌这是工资现象制造的假象本身——正是题目要你剥掉的那层皮

易错点

  • 选 D（最像生活常识）：「干一天活拿一天钱」= 把现象当本质。命题专设此项，因为它就是工资形式所要制造的效果；哲学-经济学考点里「现象≠本质」在这道题上的落点就是它。
  • 选 C：把「工人创造的价值大于工资」错记成「工资里含一部分剩余价值」——方向反了：超出工资的那部分才是剩余价值，它恰恰不在工人手里。
  • 选 A：从资本家的支付行为倒推范畴本质——「预付」描述的是资本循环里的垫付环节（货币资本购买劳动力），而题目问的是这笔钱是什么（劳动力价值的转化形式）。
记忆锚点：劳动 ≠ 劳动力；工资 = 劳动力的价值或价格（≈必要劳动），不是全部劳动的报酬；劳动创造的价值 − 劳动力价值 = 剩余价值（归资本家）。

zz-2012-04

资本积累与两极分化
1 分

2011年9月以来美国爆发的“占领华尔街”抗议活动中示威者打出“我们是99%”的标语，向极富阶层表示不满。漫画所显示的美国社会财富占有的两极分化，是资本主义制度下：

答案

答案：C

4

本题讲解：「我们是 99%」——两极分化为什么是资本积累的必然结果

答案：C（资本积累的必然结果）。

第 0 步：先立机制——资本积累这台机器怎么转

先明确概念：资本积累 = 剩余价值转化为资本（剩余价值的资本化），即资本家不把剩余价值全部消费掉，而拿出一部分去购买追加的生产资料和劳动力，进行扩大再生产。这台机器靠两股力量驱动，停不下来：

  1. 内驱：剩余价值规律——为追逐更多剩余价值，必须扩大规模；
  2. 外压：竞争规律——不积累就要被吞并，积累成了生存强制。

于是链条滚动：剩余价值 → 资本化 → 资本规模扩大 → 雇佣的劳动力更多、支配的社会财富更多 → 产生更多剩余价值 → 更多资本化……每一轮都让资本一方更重。

第 1 步：积累的必然结局——两极分化（资本主义积累的一般规律）

积累推进的同时，资本有机构成提高（技术进步，不变资本占比上升），对劳动力的相对需求下降 → 相对过剩人口扩大，劳动力供给过剩压住工资水平。于是社会财富的分配出现两极：

一极另一极
财富（资本、社会财富）在资本家一方积累、集中贫困、劳动折磨、失业在雇佣劳动者一方积累

这就是资本主义积累的一般规律：两极分化不是偶发的政策失误、不是某次金融危机的意外，而是资本积累机制自身运转的必然产物。「我们是 99%」的标语、漫画里美国社会财富占有的两极分化，正是这条规律的现实注脚——99% 与 1% 的对立，就是贫困一极与财富一极的对立。

预判追问：「必然」二字强在哪里？ 它把因果钉在制度上：只要剩余价值转化为资本的机制在运转，两极分化就会再生产出来；改变领导者、修补金融监管都动不了这个根。这正是「必然结果」与「集中表现」「恶果」这类描述性选项的分界线。

第 2 步：对号入座

选项判断理由
A 劳资冲突的集中表现❌两极分化会加剧劳资冲突，但选项解释不了分化从哪来——问的是「是什么的产物」，答成了「表现为什么」
B 生产社会化的必然产物❌生产社会化与资本主义私人占有的矛盾是基本矛盾，它解释的是资本主义的历史命运；两极分化的直接机制是资本积累
C 资本积累的必然结果✅财富一极与贫困一极同步积累——资本主义积累的一般规律的教科书表述
D 虚拟资本泡沫化的恶果❌金融泡沫是表层诱因，解释不了两极分化长期、制度性的存在；时事情境（华尔街、泡沫）只是载体

易错点

  • 选 B（背得最熟的大词最危险）：「基本矛盾」是对的原理但配错题——它管的是资本主义整体命运；题目问财富两极分化从哪来，要从「剩余价值→积累→两极」的链条上答。
  • 被时事情境带偏选 D：漫画、占领华尔街、泡沫都是叙事外壳，考点在政治经济学原理；把「恶果」当因果分析，就掉进了命题的情境陷阱。
  • 选 A：把「产物的表现」与「产物的原因」混为一谈——劳资冲突与两极分化互为表里，但题目问的是后者的制度来源。
记忆锚点：剩余价值 → 资本积累 → 财富与贫困两极同步积累（资本主义积累的一般规律）→「99% 对 1%」。

zz-2012-05

调查研究与实事求是
1 分

毛泽东曾在不同的场合多次谈到，调查研究有两种方法：一是走马看花、一是下马看花。走马看花，不深入，还必须用第二种方法，就是下马看花，过细看花，分析一朵花。毛泽东强调“下马看花”的实际意义在于：

答案

答案：D

5

本题讲解：「下马看花」——只有深入实际，才能找出规律

答案：D（只有全面深入地了解中国的实际，才能找出规律）。

第 0 步：先立机制——调查研究两种方法各管一段

毛泽东把调查研究比作两种看花法。先弄清这两个比喻各自解决什么问题：

方法动作能拿到什么缺什么
走马看花骑马掠过花田，面上概览全局的大略面貌不深入，材料粗、散、浅
下马看花下马驻足，过细地分析一朵一个点上全面而细致的材料（单靠它也不够面）

两者是面上概览 + 点上深入的配合关系。题干的关键句是「走马看花，不深入，还必须用第二种方法」——「还必须」三个字把重心钉在深入上：光有面上的概览不行，必须下马，深入到具体实际中去。

第 1 步：「实际意义」落在哪一层

题眼是「下马看花的实际意义」。把它拆开：下马 → 深入中国社会的具体实际；过细看花 → 对具体情况作过细的分析。这样得来的全面深入的材料，才能支撑认识的下一步——从实际中找出规律。这正是实事求是思想路线在调查方法上的运用：实事求是 = 从实际出发 + 找出规律（「是」即规律），调查研究是「实事」这道前半工序。所以「下马看花」的意义不在方法的花样，而在深入实际以认识规律这条认识路线上。

预判追问：为什么落脚点是「规律」而不是「材料」？ 调查是手段，认识规律、指导革命才是目的——毛泽东谈调查研究从来不是为了「了解情况」了事，而是为了给中国革命找出「什么样能成、什么样不能成」的规律性认识。选项 D 恰好完整地走完「深入实际 → 找出规律」全程，其他选项都停在中途。

第 2 步：对号入座

选项判断理由
A 解决实际问题必须要有先进理论的指导❌正确命题但答非所问：题干讲调查方法（认识从实际中来），未涉及理论指导这一环
B 运用多种综合方法分析调查研究的材料❌被「一是……一是……」的并列句式引向「方法多样」，但「还必须」点明的重心是深入，不是方法的花样多
C 马克思主义理论必须适合中国革命的具体实际❌方向反了：它讲「理论」一侧如何贴合实际（理论联系实际），「下马看花」强调的是认识从实际出发；且把具体调查方法泛化成一般命题
D 只有全面深入地了解中国的实际，才能找出规律✅下马（深入）＋过细（分析）→ 全面深入的材料 → 找出规律；与「实际意义」的落点严丝合缝

易错点

  • 选 C（最像「标准话」）：C 本身是正确命题——这正是干扰项的高配形态：对的命题，错的对位。它属于「理论与实际相结合」层面；题目考的是「从实际出发」层面（唯物论的反映论），两个层面不能互换。

  • 选 A：把「理论指导实践」的通行表述套上来——但这恰恰走的是「理论 → 实际」方向，与「下马看花」的「实际 → 认识」方向相反。
记忆锚点：走马看花 = 面上概览（不深入）；下马看花 = 点上深入、过细分析——深入实际、占有全面而细致的材料，方能实事求是找出规律。

答案

答案：D

6

本题讲解：公有制与它的实现形式——「归谁所有」≠「怎么组织经营」

答案：D（组织形式与经营方式）。

第 0 步：先立机制——一个问题拆成两个层次

改革开放以来对公有制认识的重大突破，就是把「公有制」这一个问题拆成两个层次，分别回答两个不同的问题：

层次回答的问题内容例子
所有制（性质）资产归谁所有生产资料的所有权归属、占有关系国家所有、集体所有
所有制实现形式（运作）资产怎么组织、怎么经营资产或资本的组织形式与经营方式股份制、承包、租赁、托管、控股

题干「明确了公有制和公有制的实现形式是两个不同层次的问题」这句提示本身就是解题钥匙：既然是两个层次，实现形式这一层就不能再用归属类的词（占有、所有）来回答。

预判追问：为什么要费力气区分这两个层次？ 因为区分之后解锁一个关键推论——性质与实现形式可以分离：同一所有制可以有多种实现形式（国有经济可以搞国有独资，也可以搞股份制），不同所有制也可以采用同一种实现形式（股份制资本主义能用、社会主义也能用）。实现形式本身不姓公也不姓私，关键看它为谁所用、谁在控股。有了这个推论，经济体制改革才能在不动所有制性质的前提下引入股份制等组织形式——「两个层次」的区分正是为此服务的。

第 1 步：题目问的是哪一层

题干问「公有制的实现形式是指资产或资本的……」——明确落在第二层：组织形式与经营方式。而「归谁所有」（占有形式、所有权归属）属于第一层的所有制性质。选 D 的逻辑不是「背定义」，而是题干自己给出的分层框架：实现形式 ≠ 所有制。

第 2 步：对号入座

选项判断理由
A 占有形式❌「占有」指向归属关系，属所有制（性质）那一层
B 分配形式❌分配方式是与所有制并行的另一范畴（分配由所有制决定），跟「实现形式」不同题
C 所有权归属❌恰是题干要与之区分开的那一层——题目整句话都在说这不是实现形式
D 组织形式与经营方式✅实现形式 = 资产（资本）采取什么组织形式、什么经营方式；股份制、承包、租赁皆属此列

易错点

  • 选 C/A（把「实现」理解成「落实所有权」）：望文生义——「实现」不是去实现归属（归属早已由所有制明确），而是所有权在企业运作中采取什么方式：谁来组织、怎么经营。这正是「两个层次」要划开的那条线。
  • 选 B（范畴串门）：分配方式与所有制相关但属另一对范畴（所有制决定分配），「实现形式」压根不在分配这条线上。
  • 忽视题干提示句：「两个不同层次的问题」这半句话替你排除了所有归属类选项——审题时漏掉它，就只能靠死记硬背去碰答案。
记忆锚点：所有制答「归谁所有」，实现形式答「怎么组织、怎么经营」；同一所有制可有多种实现形式，同一实现形式可为不同所有制所用——股份制不姓公不姓私，关键看谁控股。

  2. 经济因素：新民主主义国家掌握的社会主义性质的国营经济，控制着国家经济命脉；
  3. 指导思想：马克思主义在整个革命进程中居于指导地位。

这些因素随民主革命的胜利不断壮大，使民主革命的发展趋势必然是社会主义——「必要准备」与「必然趋势」由此接通，这就是「有机连接」的内在根据。

  • C 对：新事物不是把旧事物一笔勾销，而是扬弃——既克服又保留，并添上旧事物容纳不了的新内容——这是优越性的来源（更强）。

一般地说，游击战争是战术问题：在内线配合正规军作战，规模小，起辅助作用——这是战争史上的常规定位。但在抗日战争中，毛泽东 1938 年 5 月发表《抗日游击战争的战略问题》，专门把游击战争作为战略问题系统论述。地位之所以升级，根源在中国的特殊战争条件：

  • 为什么：①保障交易安全与合理信赖——对方基于承诺安排生产生活，背信即损害信赖利益；②降低社会交往成本——普遍诚信使合作不必事事设防；③维护正常的经济秩序——工资支付、合同履行都以信用为纽带。
  • 对应材料：孙东林与农民工之间是劳动（劳务）法律关系，按时足额支付工资是法定义务；兄遭变故仍代兄清偿，是把法律义务的履行升华为道德自觉——法律是底线，诚信让底线之上更有温度。

易错点

  • 第(1)问只复述事迹不提炼：事迹是论据，得分点是"诚信的内涵 + 个人、经济、社会三个层面 + 行动→信任→感召的机制"，堆故事不给分。
  • 第(2)问只背概念不答"为什么"：要落到交易安全、合理信赖、降低成本、维护秩序，并回扣"工资支付是法律关系中的义务"这一材料事实。
  • 道德法律两张皮：好的答案会点出二者贯通——诚信既是道德要求，也是法律原则，材料正是"法律义务 + 道德自觉"的叠加。
记忆锚点：诚信三层 = 立身之本 + 信用经济之基 + 社会有序之要；道德力量 = 行动担责 → 建立信任 → 形成感召；法律诚信 = 行使权利、履行义务都讲信用——保障安全、降低成本、维护秩序。

本题讲解：国家形象片——"国家公关时代"的原因与软实力的作用

答题要点：第(1)问答"为什么此时主动出击"——经济全球化下中国与世界联系空前紧密，国际社会需要准确了解中国，中国也需要主动表达自身发展和主张、消除误解偏见，并已具备实力与自觉；第(2)问答"有什么用"——形象传播展示人民生活、文化和价值追求，增进理解信任与吸引力，真实透明的表达与国内发展实践共同构成软实力基础。

第 0 步：先立机制——"公关"一词的题眼

"国家公关"的题眼在主动二字。材料3说"如此集中地向西方展示中国国家形象还是第一次"——过去中国的形象多由他人描述（"他塑"），误读与偏见丛生；形象片意味着中国从"被描述"转向"自塑"。为什么要转？材料给了三重背景：时报广场百年"鲜有中国人的面孔和身影"（存在感与话语权不匹配）→ 2011 年中国已是世界第二大经济体（实力有了，形象与实力不匹配）→ 评论聚焦"软实力"（国际竞争已从硬实力延伸到吸引力、话语权的竞争）。第(1)问的"原因"就藏在这条链里；第(2)问看形象片传递了什么——自信微笑的普通人（《人物篇》）、《角度篇》70% 以上画面是普通百姓、不回避农民工生存现状——软实力的核心正是吸引力与认同感。

第 (1) 问：分析"中国开始步入国家公关时代"的原因（4 分）

  • 联系紧密是客观基础：经济全球化深入发展，中国的前途命运日益与世界紧密相连，中国的和平发展需要良好的国际舆论环境；
  • 国际社会"想了解"：中国的发展举世瞩目，国际社会需要准确、真实、立体地了解中国；
  • 中国"要表达"：主动介绍自己的发展道路与主张，消除误解与偏见，"自塑"而非任人"他塑"，是更好参与国际事务、承担大国责任的需要；
  • 能力与自觉已具备：综合国力增强，开展公共外交、塑造国家形象的条件成熟、意识自觉。

预判追问：为什么选在时报广场、领导人出访前夕？ 传播场景是答案的注脚：在"世界的十字路口"高频滚动、与高层外交节点呼应，说明这是主动设置议题、面向国际主流社会的公共外交行动——"公关"的实质是用现代传播手段参与国际话语竞争，而不是一般的商业广告投放。

第 (2) 问：国家形象宣传对提升中国软实力的作用（4 分）

作用机制材料对应
展示真实中国用人的故事传递生活、文化与价值追求，比抽象宣传更有说服力杰出代表 + 感动中国的普通百姓；《角度篇》70% 以上画面是普通百姓生活
增进理解信任不回避问题反而增强可信度，可信才有吸引力农民工生存现状多次出现，"读出一个比较真实、鲜活的当代中国"
提升吸引力与影响力自信平和的形象产生亲近感，提高国际吸引力、感召力与沟通能力"让人油然而生到中国看看的愿望"
改善舆论环境主动沟通为和平发展营造有利外部氛围"中国国际形象公关"的主动出击，展示软实力

收口：软实力 = 文化、价值观、国家形象等产生的吸引力与感召力（区别于经济、军事等硬实力）。形象片是软实力的传播放大器，但根基仍在国内发展实践——真实、透明的表达与实实在在的发展成就共同构成软实力，二者缺一不可。

易错点

  • 第(1)问答成"有钱了做广告"：要答"需要 + 必要 + 可能"多重原因（联系紧密、消除偏见、实力支撑），落点在话语权与公共外交，不能只谈经济。
  • 第(2)问把软实力说成经济军事实力：软实力特指文化、价值观、形象带来的吸引力、感召力，混淆硬实力直接跑题。
  • 忽略"不回避问题"这一细节：真实透明才可信——这是材料2埋给第(2)问的关键提示，漏掉会丢"增进信任"这一采分点。
记忆锚点：公关时代 = 联系紧密 + 想了解 + 要表达，从"他塑"到"自塑"；软实力作用 = 展示真实 → 增进信任 → 产生吸引 → 改善环境，根基在国内发展实践。
