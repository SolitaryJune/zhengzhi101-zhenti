zz-2017-01

主观能动性与客观规律
1 分

某地区进入供暖季后常出现雾霾，而一旦出现大风天气或等到春暖花开后雾霾就会散去减少，从该地区较长时间的数据变化看，经过人们努力治霾，污染物排放总量在持续走低，但在某些时段，环境空气质量污染指数会迅速攀升，甚至“爆表”，这种看似“矛盾”的现象凸显了大气污染防治的一个特点：天帮忙很重要，但人努力才是根本。“人努力”与“天帮忙”之间的关系对我们处理主观能动性和客观规律之间辩证关系的启示是:

答案

答案：A

1

本题讲解：「人努力」与「天帮忙」——主观能动性与客观规律的辩证关系

答案：A（尊重事物的客观规律是正确发挥主观能动性的前提）。

第 0 步：先立机制——这对关系只有两条标准结论

主观能动性与客观规律的辩证关系，教材结论就两条，做题前先把它们立起来，再让选项来"对号"：

  1. 尊重客观规律是正确发挥主观能动性的前提和基础。规律是事物运动发展中本质的、必然的、稳定的联系，具有不以人的意志为转移的强制性——顺规律办事才能成，逆规律去"能动"必然碰壁。所以"尊重"必须排在"发挥"之前，它是前提。
  2. 实践是客观规律性与主观能动性相统一的基础。人只有在改造世界的实践中，才能认识规律、利用规律，把"天"的必然变成"人"的自由。"知道"靠认识，"做到"靠实践，把两者接通的是实践。

题眼一句话："天帮忙很重要，但人努力才是根本。"对号入座："天帮忙" = 客观规律（大风扩散、气候条件）在起作用；"人努力" = 发挥主观能动性（减排治污）。题问"启示"，即"人努力要干成事，得先怎么办"——按第 1 条，前提是先摸清并顺应"天"的规律，直接锁定 A。

第 1 步：预判追问——为什么"前提""基础"不能给别人

  • 为什么"掌握规律的前提"不是思想活动（B）？ 人脑想得再多，也只是主观领域里的活动，规律本身藏在客观过程里，只有通过实践（去测、去治、去试）才能被掌握。思想活动是发挥能动性的表现，不是掌握规律的前提——B 恰好把位置坐反了。
  • 为什么"统一的基础"不是认识（C）？ 认识活动只解决"知道规律"，客观规律性与主观能动性要真正"统一"，必须是在实践中既尊重规律又改造世界——认识是环节，实践才是基础。
  • 为什么不是"尚未认识的规律"（D）？ 题干说的恰是人们已认识了雾霾成因、并顺应规律持续减排（"人努力才是根本"）；D 把题眼重心从"人努力"滑向"未知的天决定一切"，答非所问。

第 2 步：干扰项归因

选项错在哪对应的误解
B关系倒置：掌握客观规律靠的是实践，"人类有意识的思想活动"不是"掌握客观规律的根本前提"把"意识能认识规律"偷换成"意识是认识规律的前提"
C偷换"基础"：使二者统一起来的基础是实践，不是"认识活动"——认识只解决"知道"，实践才把"知道"与"做到"接通用"认识"冒充"实践"的基础地位
D答非所问：题干说的恰恰是人已认识并顺应规律、持续减排治霾，不是"尚未认识的规律"在起"至关重要的作用"把题眼重心从"人努力"滑向"未知的天决定一切"

易错点

  • 看到"人努力才是根本"容易选 B："有意识的思想活动"听起来很"能动"，但设问求的是"启示"——正确处理这对关系的条件，标准表述只有"尊重客观规律是前提"。
  • "前提/基础"两个词要盯死：发挥能动性的前提是尊重规律；二者统一的基础是实践。B、C 分别在这两个词上做文章。
记忆锚点：尊重规律是前提，实践是统一的基础；"天帮忙" = 客观规律，"人努力" = 主观能动性，人努力先得顺着天的脾气。

意识的本质
1 分

有人认为，既然人的意识是对客观外部世界的反映，那么人脑里的“鬼”、“神”意识就是对外在世界鬼、神真实存在的反映。这种观念错误在于

答案

答案：C

2

本题讲解：鬼神观念反映什么——意识是客观存在的主观映象

答案：C（认为意识是对存在的直接反映）。

第 0 步：先立机制——"反映"不等于"照镜子"

意识是客观世界的主观映象，这句话包含两层意思，缺一层就会掉进题里的坑：

  1. 素材层（从哪里来）：一切意识都能在现实世界中找到它的原型或素材，鬼神观念也不例外——鬼的样子拆开看是"人 + 动物 + 传说素材"的拼接，绝非凭空。
  2. 方式层（怎么反映）：反映有两种方式。摹写性（直接反映）：原型是什么，观念里就映成什么；创造性：对现实素材进行加工、重组、虚构（歪曲的反映）。"看见苹果 → 产生苹果的观念"是摹写，"拼出龙、鬼、神"是创造。

题中观点的推理链是："意识是对外部世界的反映 → 头脑里有鬼神观念 → 外部世界真实存在鬼神"。第一步没错，坏在第二步：它把一切反映都当成镜像式的直接反映，不承认观念可以是对现实素材的加工与虚构。观念存在 ≠ 原型实体存在——这正是 C 的表述。

第 1 步：预判追问——三个干扰项为什么"看着也像"

  • 为什么不是 A（夸大了意识的能动作用）？ 辨方向：题中观点把意识当成只会照原样成像的镜子，恰恰是抹杀了意识的创造性；"夸大能动作用"指的是"意识创造万物""人有多大胆"那类命题。这里的错误是少承认了能动性，不是夸大。
  • 为什么不是 B（把意识看成物质的产物）？ 这句本身是唯物主义的正确命题（意识是物质世界长期发展的产物、人脑的机能）。题中观点错在"反映的方式"，不在"意识的来源"——正确命题 ≠ 题目所问的那个错误。
  • 为什么不是 D（混淆意识自然演化的阶段）？ 意识的自然演化讲的是起源史：无生命物质的反应特性 → 低等生物的刺激感应 → 动物的感觉心理 → 人类意识。题问的是鬼神观念反映什么（本质问题），起源的时间线帮不上忙，答非所问。

第 2 步：干扰项归因

选项错在哪对应的误解
A方向说反了：题中观点抹杀意识的能动性（创造性加工），不是夸大见"意识"二字就条件反射往"能动性"上靠
B唯物主义的正确命题，但题中观点错在反映方式，不在意识来源把"正确命题"当成"题目要找的错误"
D答非所问：演化阶段讲意识起源，题问鬼神观念反映什么拿"意识的起源"知识硬套"意识的本质"

易错点

  • 最顺手选 A：题干表面在谈"意识"，容易条件反射选"能动性"。要辨方向——题中观点是把反映机械化，错在少承认了创造性，不是夸大了能动性。
  • "鬼神观念也是对存在的反映"这句话本身没错（素材来自现实），错的是由此推出鬼神实体存在。辨析要看推理走在哪一步断裂。
记忆锚点：一切观念都有现实素材，但反映分摹写与创造；鬼神 = 对存在的歪曲反映，头脑里有 ≠ 现实中存在。

zz-2017-03

平均利润与生产价格
1 分

某企业投资汽车生产。生产一辆汽车所耗费的生产资料价值为15万元，支付给工人的工资为5万元，假定市场的平均利润为10%，那么，在自由竞争条件下，该汽车的生产价格是

答案

答案：D

3

本题讲解：生产价格 = 成本价格 + 平均利润

答案：D（22 万元）。

第 0 步：先立机制——自由竞争下，商品按生产价格卖

题干三个数：生产资料价值 c = 15 万，工资（可变资本）v = 5 万，平均利润率 10%。求"自由竞争条件下"的生产价格——这个限定词就是机制入口：自由竞争使资本在部门间自由转移，利润率低的部门资本流出、高的部门资本涌入，各部门利润率平均化。平均化之后，商品不再按价值（c+v+m）出卖，改按生产价格出卖。生成链三步：

  1. 成本价格 k = c + v：生产上实际耗费的资本——生产资料转移价值加上付出去的工资；
  2. 平均利润 p = k × 平均利润率：利润平均化后"等量资本得等量利润"，10% 乘的是全部预付资本 k，不能只乘 c 或只乘 v；
  3. 生产价格 = k + p。

第 1 步：三步代入

步骤算式结果
成本价格k = 15 万 + 5 万20 万元
平均利润p = 20 万 × 10%2 万元
生产价格k + p = 20 万 + 2 万22 万元

第 2 步：预判追问——两个最容易问的"为什么"

  • 为什么 10% 乘的是 k 整体（20 万），而不是可变资本 v（5 万）？ 因为这里用的是利润率而非剩余价值率：利润率 p′ = m ÷ (c+v)，是对全部预付资本而言的增殖程度；剩余价值率 m′ = m ÷ v 才只对 v、反映剥削程度。利润平均化后按"等量资本得等量利润"分配，分母必须是 c+v 整体。
  • 为什么题干没给剩余价值 m，也能算出生产价格？ 因为生产价格公式里根本不含该企业实际榨取的 m——平均利润由"平均利润率 × 成本价格"决定，是这个企业按资本量分到的利润份额，不是它自己创造的剩余价值。这正是平均利润理论的要点：利润的来源（本部门工人创造的 m）与利润的取得（按资本量均分）分开了。

第 3 步：干扰项归因——三个错答各自"乘漏了谁"

选项数值从哪来对应的误解
A 20 万恰是成本价格 k 本身只走第 1 步，把"成本价格"当"生产价格"，漏加平均利润
B 20.5 万5 × 10% = 0.5，20 + 0.5把 10% 只乘可变资本 v——利润率是对全部预付资本而言的，不是只对工资
C 21.5 万15 × 10% = 1.5，20 + 1.5把 10% 只乘生产资料 c——乘数分母被拆成一半

易错点

  • 题干"市场的平均利润为 10%"要读成"平均利润率 10%"，作用对象是 k 整体。看到"工资"就想只乘 v、看到"生产资料"就想只乘 c，正是命题人预设的两个坑。
  • 记不清公式时先背结构："生产价格 = 成本价格 + 平均利润"；成本价格 = c + v，平均利润率的分母不能拆。
记忆锚点：k = c + v；p = k × 平均利润率；生产价格 = k + p = 20 + 2 = 22 万。10% 乘的是 k 整体，分母不能拆。

资本主义所有制
1 分

从历史发展的角度看，资本主义生产资料所有制是不断演进和变化的，当今资本主义社会居主导地位的资本所有制形式是

答案

答案：B

4

本题讲解：资本主义所有制的演进——当今居主导的是法人资本所有制

答案：B（法人资本所有制）。

第 0 步：先立机制——所有制形式跟着"资本占有主体"走

资本主义生产资料所有制的演进，本质是资本占有主体在一步步换人：从自然人个人 → 联合起来的自然人股东 → 联合起来的"法人"。把它排成时间线，"当今谁主导"就不需要死记，顺着轴读就行：

阶段形式占有主体与经营地位
19 世纪末以前私人资本所有制资本家个人占有生产资料，所有者亲自经营（所有权与经营权合一）早期主导
19 世纪末 20 世纪初私人股份资本所有制单个私人资本联合为股份资本，所有权与经营权分离；但持股主体仍是自然人股东，性质仍属私人资本当时的主导
二战后，尤其 20 世纪 70 年代以来法人资本所有制占有主体从个人资本家变为法人（企业、机构等法人组织互相持股）当今居主导地位

为什么战后法人会取代自然人成为占有主体？股份制普及后，持股的主力从分散的个人股东变成了企业、基金会等法人组织——资本的组织方式升级了，占有主体自然跟着换代。但要看穿一层：这些形式再怎么变，占有制性质仍是资本主义私有制，变化的是实现形式，不是剥削性质。

第 1 步：题眼对号入座

题问"当今资本主义社会居主导地位的资本所有制形式"——把时间轴拨到"当代"，落点就是法人资本所有制，选 B。

第 2 步：预判追问——C 为什么不行

私人股份资本所有制是最有迷惑性的干扰项：股份公司至今普遍存在，为什么主导形式不是它？分界线一句话：私人股份资本 = 自然人股东持股；法人资本所有制 = 法人持股。战后持股主力已从自然人升级为法人组织——股份制这台"车"还在跑，但"驾驶人"换了，教材按占有主体命名主导形式。

第 3 步：干扰项归因

选项错在哪对应的误解
A私人资本所有制（个人占有、亲自经营）是 19 世纪末以前的早期形式，早被股份制取代把"资本主义私有制的原型"当成现状
C私人股份资本所有制是 19 世纪末 20 世纪初的主导形式；战后持股主体已从自然人升级为法人停在"股份制"这一步没往前看——C 与 B 的分界线恰恰是"私人 vs 法人"
D"垄断资本私人所有制"不是教材对所有制形式的规范表述；垄断讲的是资本的集中程度（自由竞争 → 私人垄断 → 国家垄断），不是一种占有主体形式拿"垄断阶段"的概念硬套"所有制形式"

易错点

  • 最有迷惑性的是 C：股份公司至今普遍存在，但题目问的是"居主导地位的所有制形式"这一规范说法，教材的答案是法人资本所有制。区分点一句话：私人股份资本 = 自然人股东持股；法人资本所有制 = 法人持股。
  • 别把"国家资本所有制"也当记忆点混淆：它虽是当代存在的形式之一，但题问的是"居主导地位"，且它不出现在本题选项中。
记忆锚点：占有主体三级跳——自然人个人 → 自然人股东 → 法人；"当今主导" = 法人资本所有制；变的只是实现形式，不是私有制性质。

zz-2017-05

新民主主义社会
1 分

从中华人民共和国成立到社会主义改造完成，是我国从新民主主义到社会主义的过渡时期。这一时期，个体经济向社会主义集体经济过渡形式是

答案

答案：C

5

本题讲解：过渡时期五种经济成分——个体经济的过渡形式是合作社经济

答案：C（合作社经济）。

第 0 步：先立机制——过渡时期的社会是一张"成分 × 去向"的网

从新中国成立到 1956 年社会主义改造完成，我国既不是纯粹的社会主义社会，也还留着旧社会的成分——五种经济成分并存。命题考"谁向谁过渡"，考的就是这张网。先把坐标立起来：

经济成分性质在改造中的位置
社会主义性质的国营经济全民所有领导力量，是各条改造线的终点形态本身
半社会主义性质的合作社经济劳动者集体占有与私有并存个体经济 → 社会主义集体经济的过渡形式
农民和手工业者的个体经济劳动者私有改造对象（起点）
私人资本主义经济资本主义私有改造对象（起点）
国家资本主义经济在人民政府管理之下的资本主义私人资本主义 → 国营经济的过渡形式

有了坐标，再记两条改造路线（起点 → 过渡形式 → 终点）：

  1. 个体经济（农业、手工业）：互助组 → 初级社 → 高级社，走合作化道路，过渡形式 = 合作社经济；
  2. 私人资本主义：加工订货 → 个别企业公私合营 → 全行业公私合营，走国家资本主义道路，过渡形式 = 国家资本主义经济。

题眼问"个体经济向社会主义集体经济过渡的形式"——在第一条路线上对号入座，就是合作社经济，选 C。

第 1 步：预判追问——为什么 A、D 都沾"大词"却不对

  • 为什么国营经济（A）不是过渡形式？ 国营经济本身就是社会主义性质，是改造要到达的目标形态，又是整个国民经济的领导力量——它站在终点上，不需要再"向社会主义过渡"。说国营经济是过渡形式，等于说终点是通往终点的那座桥。
  • 为什么国家资本主义（D）不能选？ D 确实是"过渡形式"，但它是另一条路线上的桥：接的是私人资本主义，通向国营经济。题眼把起点限定为"个体经济"——起点不同，桥就不同。命题人把 D 放在这里，专考"两条路线不要串线"。
  • 合作社为什么叫"半社会主义"？ 初级社里土地入股、统一经营，社员既有私有的土地分红，又有集体积累——私有因素与社会主义因素并存，所以是"半"社会主义；到高级社土地归集体，才完全公有化。这种"一半旧一半新"的形态，恰好说明它是过渡的桥。

第 2 步：干扰项归因

选项错在哪对应的误解
A社会主义性质的领导力量，是目标不是桥把"终点"当成"过渡形式"
B本身是被改造对象，属资本主义改造那条线看见"资本主义"四个字就忘了题眼限定"个体"
D过渡形式没错，但接的是私人资本主义那条线只认"过渡"两个字、不核对起点——最强干扰项

易错点

  • 最容易选 D："过渡形式"四个字对了就冲上去——必须再核对起点：个体经济的桥是合作社，不是国家资本主义。
  • 两条路线别串线：农业/手工业（个体）→ 合作社；资本主义工商业 → 国家资本主义。
记忆锚点：个体经济 → 合作社经济（半社会主义性质）；私人资本主义 → 国家资本主义；国营经济是领导力量和终点形态，不是过渡形式。

权利归属政策取向

第 0 步：先立机制——信念体系是一座有层次的"塔"

题干先把定义交到手上：信念是认知、情感和意志的有机统一体——认知是底座（知道并相信它有道理），情感是黏合剂（认同它、热爱它），意志是支柱（下决心排除困难去践行它），三者合成"坚信不疑并身体力行"的心理态度和精神状态。正因为三个成分合成一个整体，信念不是零散想法的堆砌，而是有结构和层次的体系——设问"信念有不同的层次和类型，其中……"，考的就是这个内部结构。

为什么会分层？因为各种信念在同一个人心里的地位并不平等：

  • 最高层：对最高理想和终极价值的坚定追求，即一个人的基本信仰，统摄整个人生方向——"信仰"二字只有高层次信念担得起；
  • 低层：对具体人、具体事、具体观念的相信，支撑日常选择，并服从、服务于高层次信念。

所以层次关系的正确表述只有一条：高层次的信念决定低层次的信念——高层定方向，低层管日常。选 A。

  1. 科学性维度：信念有科学与非科学之分。科学的信念建立在对客观规律的正确认识之上；"坚信不疑"只说明态度坚定，不等于内容正确——否则教材就不会要求"确立科学的信念"了。
  2. 主体差异维度：信念具有多样性和差异性。即使社会环境相同，人们的信念也会因立场、经历、利益、教育不同而不一致——同环境不等于同信念。

人的实践活动从来不是单尺测量，而是双尺同时校准：

  • 真理尺度：按客观规律办事，回答"客体是什么、能做什么"——这是事实判断，只认客体的属性与规律，不随人的好恶改变；

价值评价为什么会"多种多样"？机制在两处：一是客体是多维的——同一事物往往既有满足需要的属性，也有造成损害的可能；二是主体是多元的——不同主体的需要、处境、利益和认识水平不同，对同一客体的价值评价自然不同。而两把尺子又不是各自为政：价值评价要以事实判断为基础，科学的评价必须是真理尺度与价值尺度的统一。

先看机制：赤溪村三十三年走出一条三级递进路线——"输血"（救济式扶贫，送钱送物，治标不治本）→ "换血"（挪穷窝，14 个自然村移民搬迁、通路通电，改善生存条件）→ "造血"（转变观念、因地制宜培育生态旅游主导产业，拔掉穷根）。个案背后是可复制的方法论：

  • 观念先行、激发内生动力："弱鸟可望先飞……首先要看我们头脑里有无这种意识"——扶贫先扶志，发挥群众主体作用；
  • 因地制宜、精准施策："必须探讨一条因地制宜发展经济的路子"——反对大水漫灌，落到精准识别、精准帮扶，印证"就是要精准扶贫"的方针；
  • 产业造血、着眼可持续：靠人均不足 1 亩的耕地拔不了穷根，要把生态优势转化为旅游产业优势，发展可持续产业、防止返贫；
  • 基础设施托底：移民搬迁、通路通电，改善生产生活条件是产业发展的前提；
  • 党建引领、久久为功：村两委带动＋党的扶贫政策支持＋社会各方帮扶，"滴水穿石、久久为功"——把外部帮助与内生动力结合起来。

易错点与预判追问

  • 只答"贫困不好、要加快脱贫"：缺少论证层次——必须按"全面小康内涵 → 不平衡不充分 → 底线任务/标志性指标"展开，才对得起"为什么是短板"的问法。
  • 第(2)问复述赤溪村事迹：材料分析题要从个案上升为方法论——写出"输血换血造血"的递进与"精准、内生、可持续"三条以上启示，光讲故事不得分。
  • 漏掉"防止返贫"与"外部帮扶＋内生动力结合"：救济式扶贫"治标不治本"这句话，就是在提示可持续性与内生动力的采分点。
  • 把共享理念只挂在嘴边：要落到"一个都不能少"与"总量≠全面"的具体机制上。
记忆锚点：短板论三层——共享性（一个不能少）＋不平衡不充分＋底线指标；扶贫三部曲 输血→换血→造血；精准扶贫 = 因地制宜＋扶志扶智＋产业可持续＋久久为功。

  • 职业普遍性（"一切"的根据）：一切正当职业都通过诚实劳动服务他人、支撑社会运行——医生面对生命、教师面对学生、焊工面对发动机，行业各异，"敬业、守信、负责、精益求精"的要求相通。职业道德不是某个行业的行规，而是对一切从业人员的共同要求。
  • 现实针对性（"呼唤"的所指）：急功近利、心浮气躁、假冒伪劣的时弊，正需要用专注坚守、精益求精来对治；"中国制造"迈向更高品质，需要的不仅是技术升级，更是职业态度升级——工匠精神"代表一个时代的气质"。
  • 人生价值层面（思修落点）：职业是人生价值实现的主要舞台——只有敬业奉献、追求卓越，才能把自我价值与社会价值统一起来；它"不仅仅是制造业的需要，也不仅仅是企业家的需要"——人皆可为、行皆适用。

易错点与预判追问

  • 第(1)问只写"认真负责"四个字：要按"爱岗敬业—精益求精—专注坚守—奉献社会"分层展开、每层配材料引证，否则 5 分只拿到空泛的 1—2 分。
  • 把工匠精神等同于"手艺人的技术"：材料明说工匠的工作"或许会逐渐被机器所取代"而精神"不可能被代替"——它是职业伦理与态度，不是技艺本身；这一点立不住，第(2)问的"一切职业"就推不开。
  • 第(2)问漏"现实针对性"：只讲"职业都该敬业"是普遍性一半；"道德呼唤"暗含对当下浮躁风气的针砭与对品质时代的期待，这层丢了要扣分。
  • 漏掉人生价值角度：本题出自思修板块，"在劳动与奉献中实现人生价值""自我价值与社会价值统一"是应有之意，纯职业道德作答不完整。
记忆锚点：实质 = 爱岗敬业＋精益求精＋专注坚守＋奉献社会；道德呼唤三理由 = 职业普遍性＋现实针对性＋人生价值舞台；机器换得走手艺，换不走精神。

本题讲解：G20 杭州峰会主题的现实意义与"桥"里的外交理念

答案要点：第(1)问——先诊断世界经济的"病"，再让创新、活力、联动、包容四个主题词逐一对症，落脚到全球经济治理与中国贡献（6 分）；第(2)问——三座桥落到伙伴关系、合作共赢、人类命运共同体（4 分）。

第 0 步：先立机制——主题词是"对症下药"的处方

设问限定"结合当前国际环境"——意味着不能把主题词当口号背，要按"先摆病 → 再讲方 → 后落医"三段走。2016 年世界经济的病有四味：增长动力不足（旧动能衰减、新动能断档）、治理机制滞后（全球经济治理体系不适应新格局）、发展失衡（南北差距拉大、最不发达国家被边缘化）、保护主义抬头（以邻为壑、联动性受损）。主题词一一对应病症，材料里的成果文件就是"处方"的证据——这是把"现实意义"答实的框架。

第(1)问：四大主题词的对症表（6 分）

主题词对应的"病"处方与材料证据
创新增长动力不足聚焦创新、新工业革命、数字经济，通过《创新增长蓝图》，为世界经济"开辟新道路、拓展新疆界"
活力体制机制之僵通过《深化结构性改革议程》，以结构性改革激发经济增长的内生活力
联动以邻为壑、各自为战互联互通、联动增长、加强宏观政策协调——"彼此包容、守望相助"，拒绝碎片化
包容发展失衡、成果不共享"三个第一次"：发展问题置于全球宏观政策框架突出位置、就落实 2030 年可持续发展议程制定行动计划、集体支持非洲和最不发达国家工业化

收拢：四大主题词为长期疲软的世界经济"准确把脉、找到病根，开出标本兼治、综合施策的良方"，推动全球经济治理朝着更加公正合理的方向发展——这正是中国作为主席国贡献的"中国智慧"的现实意义。

第(2)问："桥"的比喻与外交理念（4 分）

  • 机制先行：桥的功能是连接与通行——用"桥"喻 G20，说的是国情不同、发展阶段不同的国家可以经由这座桥走向彼此、走向共同未来。三座桥各有所指：
  • 友谊之桥 → 伙伴关系：结伴而不结盟，"彼此包容、守望相助"，超越冷战思维与阵营对抗；
  • 合作之桥 → 合作共赢、共商共建共享：28 份成果文件正是"大家的事大家商量着办"的产物；
  • 未来之桥 → 互联互通、联动发展：让增长与发展成果惠及各方，指向人类命运共同体。
  • 世界情怀落点：中国从 G20 的参与者、建设者、贡献者，跃变为全方位的协调者和强有力的主导者；中美元首率先交存《巴黎协定》批准文书，为会议定下建设性基调——负责任大国的担当：做世界和平的建设者、全球发展的贡献者、国际秩序的维护者。

易错点与预判追问

  • 只抄主题词、不摆"病"：题干明写"结合当前国际环境"——没有"动力不足、治理滞后、发展失衡、保护主义"的诊断，主题词就成了无的之矢，6 分先丢 2—3 分。
  • 四个词混着写、不做对应：每个词对应一种病症与一类成果文件（蓝图、议程、行动计划），按词分点才能踩满采分点。
  • 把"联动"写成"经济全球化"一笔带过：联动要落到互联互通＋政策协调＋拒绝以邻为壑的具体机制。
  • 第(2)问只写"和平合作"等泛词：要落到规范表述——伙伴关系、合作共赢、共商共建共享、互联互通、人类命运共同体，再补"参与者、建设者、贡献者 → 协调者、主导者"的角色变化。
  • 漏用材料：28 份成果文件、"三个第一次"、潘基文"历史性的贡献"都是现成的采分证据，只讲课本话术不引材料会显得空洞。
记忆锚点：创新＝找动力、活力＝促改革、联动＝强协调、包容＝促共享；三座桥 = 友谊（伙伴关系）＋合作（共赢、共商共建共享）＋未来（命运共同体）；中国角色 = 参与者、建设者、贡献者 → 协调者、主导者。
