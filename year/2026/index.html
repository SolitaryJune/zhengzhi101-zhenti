zz-2026-01

联系与发展
1 分

“十五五”时期在基本实现社会主义现代化进程中具有承前启后的重要地位，习近平总书记在《关于〈中共中央关于制定国民经济和社会发展第十五个五年规划的建议〉的说明》中指出，实现社会主义现代化是一个阶梯式递进、不断发展进步的历史过程，需要不懈努力、接续奋斗。“阶梯式递进、不断发展进步”的过程是一个
①前进性和曲折性相统一的过程
②规律性和能动性相统一的过程
③连续性和非连续性相统一的过程
④直线性和循环性相统一的过程

答案

答案：A

1

本题讲解：「阶梯式递进、不断发展进步」体现哪些统一

答案：A（①②③）。

第 0 步：先立模型——辩证唯物主义怎么看「发展」

发展观上有两个立场：辩证法认为发展是前进性与曲折性的统一、连续性与非连续性（阶段性、飞跃）的统一；形而上学则要么把发展看成一路平坦的直线（直线论），要么看成周而复始的圆圈（循环论）。此外，人的实践发展还离不开规律性与能动性的关系：既要遵循客观规律，又要发挥主观能动性。「阶梯式递进、不断发展进步，需要不懈努力、接续奋斗」这句话，恰好把三个维度都装进去了：

维度「阶梯式递进」对应的侧面
① 前进性 + 曲折性总方向是发展进步（前进性），但「需要不懈努力、接续奋斗」说明道路有起伏（曲折性）
② 规律性 + 能动性递进遵循现代化建设的客观规律，同时靠「接续奋斗」发挥主观能动性去实现
③ 连续性 + 非连续性「阶梯式」＝台阶之间连续衔接（连续性），上一级台阶是一次阶段性跃升（非连续性）
④ 直线性 + 循环性形而上学发展观：直线论否认曲折，循环论否认前进，均属片面

第 1 步：逐条对号

  • ①对：现代化进程总趋势是「不断发展进步」（前进性），但「需要不懈努力、接续奋斗」正说明不会一帆风顺（曲折性）。
  • ②对：实现社会主义现代化是客观历史过程，有自身规律；「不懈努力、接续奋斗」是发挥主观能动性——规律性与能动性统一。
  • ③对：「阶梯式递进」——台阶逐级而上、连续衔接（连续性），每一级台阶是一次质变与跃升（非连续性）。
  • ④错：直线论把发展看成无曲折的直线，循环论把发展看成原地打转；「不断发展进步」恰恰否定了循环，「接续奋斗」恰恰否认了直线。

易错点

  • 把「循环性」当正确（误选 B/C/D）：循环论把发展看成周而复始、原地打转，否认前进性；「阶梯式」的「上一级台阶」是螺旋式上升，不是封闭圆圈。
  • 把「直线性」当正确：直线论否认道路曲折；题干「不懈努力、接续奋斗」正说明道路不平坦。
  • 漏掉②（误选 C）：只盯住「阶梯式」的形状，漏了「需要不懈努力、接续奋斗」这半句——它对应主观能动性，是②成立的关键证据。
记忆锚点：发展 = 前进性×曲折性 + 连续性×非连续性；「接续奋斗」这类字眼对应能动性；直线论、循环论一律片面。

联系与客观规律
1 分

一般认为，在重力的作用下，当树叶飘移枝头坠落地面时，密度大的叶片正面更容易朝下着地。科学研究表明，叶片的下落过程并非简单的直线下落，因为叶片形状并非完全对称，加之空气阻力差异、涡流和风等因素影响，叶片以翻滚和旋转的复杂运动形态下落。内部结构差异与外在形态变化，在一定程度上影响着叶片的飘落状态，旋转动能和空气阻力也是影响叶片在下降过程中朝向的因素。叶片下落过程表明，事物运动的规律

答案

答案：D

2

本题讲解：叶片飘落揭示「规律」是什么

答案：D（是各种因素相互作用的结果）。

第 0 步：先立模型——规律是「联系」，不是某个单独因素

先想清楚规律的定义：规律是事物运动发展中本质的、必然的、稳定的联系。既然规律是一种联系，它就不会「取决于」某一个单独的因素，而是存在于事物内部诸要素以及事物与外部条件的相互作用之中。把题干给的现象链拆开：

因素类型在飘落中的作用
叶片形状不完全对称内部结构使受风受力不均，下落轨迹偏离直线
空气阻力差异、涡流外部条件与叶片形态互动，产生翻滚、旋转
风外部条件参与改变下落朝向
旋转动能运动状态内外因素交互的产物，反过来又影响朝向

题干自己的用词是「内部结构差异与外在形态变化，在一定程度上影响着叶片的飘落状态」——内部与外部因素共同参与、相互影响。

第 1 步：把现象链对进「规律」定义

叶片以翻滚和旋转的复杂形态下落、密度大的正面更容易朝下，这不是任何单一因素的功劳，而是形状、阻力、涡流、风、旋转动能等多种因素相互作用形成的稳定趋势——「正面更易朝下」可重复出现，是必然联系。这正是「规律存在于事物内部及诸因素的相互作用中」。

第 2 步：逐项排查

选项判断归因
A 取决于外在因素作用的大小❌规律是事物自身本质的联系，不由外部因素「大小」决定；叶片内部结构差异同样在起作用
B 是纯粹偶然因素作用的结果❌「正面更容易朝下」可重复出现，是必然性；偶然性背后隐藏着必然性，「纯粹偶然」本身不成立
C 取决于物质运动形态的结果❌规律是运动中的本质联系，说它「取决于结果」把联系与结果搞颠倒
D 是各种因素相互作用的结果✅与「内部结构差异＋外在形态变化共同影响飘落状态」的现象链完全吻合

易错点

  • 选 B（「翻滚旋转」看着乱）：把「轨迹复杂」误当成「无规律」——复杂不等于偶然，翻滚与旋转本身有稳定的力学联系。
  • 选 A（「风、涡流」印象深）：只盯外部显眼因素，漏了题干「内部结构差异」半句；规律不由外在因素单独决定。
  • 选 C（拿「运动形态」套词）：把「物质运动形态」当帽子乱扣——规律不是「结果」，更不会「取决于结果」。
记忆锚点：规律 = 本质的、必然的、稳定的联系；联系 → 相互作用 → 不是单一因素说了算。

主观能动性与客观规律
1 分

孙子兵法将变化视为军事运行常态，认为“兵无常势，水无常形”，要将战争的主动权始终掌握在自己手中，根据不同的情况灵活应对，由此可知，“兵无常势，水无常形”契合了

答案

答案：C

3

本题讲解：「兵无常势，水无常形」契合哪句话

答案：C（「意志自由只是借助于对事物的认识来做出决定」的观点）。

第 0 步：先立机制——「灵活应对」的自由从哪里来

孙子讲「兵无常势，水无常形」，要求根据不同的情况灵活应对，把战争的主动权始终掌握在自己手中。这句话翻译成哲学问题就是：指挥战争的「自由」（灵活应对的能力）从哪里来？ 马克思主义哲学的回答是一条因果链：

  1. 战争规律客观存在（必然），但它的表现形式因时因地而变——这就是「无常势、无常形」；
  2. 要掌握主动权，第一步不是「变」，而是先认识具体条件下的实际与规律（知彼知己）；
  3. 认识了必然，才能据此做出决定、灵活应变。

恩格斯正是这样界定的：「自由不在于幻想中摆脱自然规律而独立，而在于认识这些规律，从而能够有计划地使自然规律为一定的目的服务」——因此「意志自由只是借助于对事物的认识来做出决定的能力」。追问一句「为什么灵活不等于随心所欲」：因为灵活性以规律性为根据；不掌握战场实际的「灵活」只是乱来，认识了必然，主动权才真正在自己手里——自由以认识必然为基础。

第 1 步：逐项对号

选项判断归因
A 「原则是研究的出发点」❌教条主义：从原则出发剪裁实际。「无常势」恰恰要求从战场实际出发——出发点是实际，不是原则
B 「理性是衡量一切的唯一尺度」❌这是恩格斯笔下十八世纪启蒙思想的口号（「思维着的悟性成了衡量一切的唯一尺度」）：尺度放在主观理性一边，缺了「认识客观事物」这一环
C 「意志自由只是借助于对事物的认识来做出决定」✅恩格斯论断：自由＝认识必然后做出决定——正合「根据不同的情况灵活应对、掌握主动权」
D 「思维的本质在于把意识的因素联合为一个统一体」❌把思维的本质归结为意识内部因素的组合，否认思维是对客观世界的反映——与把握战场必然无关

易错点

  • 选 A（把「活用原则」混同「从原则出发」）：孙子的逻辑是先察战场实际、再定打法；「从原则出发」颠倒了认识路线（实际→原则，而非原则→实际）。
  • 选 B（只看「理性」像「智慧指挥」）：词面迷惑。关键看尺度在哪一边——「唯一尺度」是主观理性，而题干的尺度是客观情况。
  • 选 D（被「统一体」字面迷惑）：「统一体」说的是意识内部因素的联合，属于否认反映论的唯心主义倾向，谈不上把握实际与规律。
记忆锚点：无常势 → 具体情况具体分析；自由＝对必然的认识＋据此做出决定；「从原则出发」＝教条主义，出发点永远在实际。

答案

答案：B

4

本题讲解：列宁论未来社会——什么必然、什么不可知

答案：B（生产力将有更大发展）。

第 0 步：先立机制——把列宁的话切成两截

科学社会主义可以预见未来，但预见的对象有严格边界。判别的尺子只有两条：

  1. 方向性、趋势性判断——由社会发展的客观规律推出，可以「绝对有把握」地说；
  2. 具体方式、速度、进程——由未来实践展开时的实际条件决定，实践尚未展开就不可能知道，只能留待实践去回答。

拿这两条读列宁原文：前一截「剥夺资本家一定会使人类社会的生产力蓬勃发展」——句式是必然判断，落在方向与趋势上；后一截「将以什么样的速度向前发展……这都是我们所不知道而且也不可能知道的」——明确把速度、进程这些细节划出预见的边界。所以题问「未来社会必然会发生的是」，答案必须落在「一定会」的那一截上。

第 1 步：逐项对号

选项判断归因
A 生产力发展的具体方式❌恰是列宁明说「不知道而且也不可能知道」的细节——把「方向可预言」误当成「细节可描述」
B 生产力将有更大发展✅原文「一定会使生产力蓬勃发展」——方向性必然判断，正是可以绝对有把握的部分
C 劳动成为生活的唯一需要❌原文是「第一需要」，且它何时、以何种速度实现正属「不可能知道」之列；「唯一」是偷换
D 实现人的无差别的全面发展❌「无差别」绝对化；打破分工、消灭对立的进程同样属「不知道」半句，不可凭空断言

易错点

  • 选 A（把预见当算命）：以为科学预见连「怎么发展」都能给出——列宁恰恰否认这一点；能预言的是趋势，不是细节。
  • 选 C（被「第一需要」原文拉走）：原文出现 ≠ 必然发生——「劳动成为生活的第一需要」确是未来图景，但选项把「第一」偷换成「唯一」，且其实现进程正属「不可能知道」的范围。
  • 选 D（把方向当定局）：「人的自由而全面发展」是方向性预见，但「无差别」把发展绝对化——即便到那时，人的发展也不是千人一面的。
记忆锚点：预见未来＝管方向、不管细节；「一定会」的才是必然，「什么样的速度与方式」留给实践去回答。

本题讲解：「解剖麻雀」的实际意义

答案：D（全面深入了解本国实际，发现本国革命的规律）。

第 0 步：先立机制——「解剖麻雀」是一种什么认识方法

毛泽东要求领导机关负责同志「亲自调查一两个农村，解剖一两只『麻雀』」，这套方法的认识论机制是由个别认识一般：

  1. 麻雀虽小、五脏俱全——每一个典型个体都包含着该类事物的共性；
  2. 深入解剖一两个典型（个别），就能透过它把握同类事物的共同本质与规律（一般）；
  3. 这正是「从实际出发、实事求是」的操作化：不坐在机关里看文件听汇报，而是亲自下去，从中国的具体实际中提炼中国革命的规律。

追问一句「为什么解剖一两只就够了」：调查研究取的不是数量，而是典型性——典型里藏着同类的一般；个别与一般相联结，解剖一只麻雀得到的是「麻雀」的规律，不是那一只鸟的私事。

第 1 步：逐项对号

选项判断归因
A 理论只有彻底，才能说服人❌马克思论「理论彻底性」的名言，讲理论自身的说服力，与「亲自调查、了解实际」的主题不对号
B 反对经验主义、尾巴主义和机会主义❌「破」的口号式表述、矛头错置——题干强调的是「立」：亲自调查、掌握实际、发现规律
C 没有革命的理论，就不会有革命的实践❌讲理论指导实践；题干走的是实践→认识（从实际中提炼规律），方向恰好颠倒
D 全面深入了解本国实际，发现本国革命的规律✅解剖麻雀＝深入实际调查研究，由个别上升为一般，认识本国革命的具体规律

易错点

  • 选 C（方向搞反）：「理论→实践」与「实践→理论」是两条不同的认识路线；「解剖麻雀」属于后者——没有调查就没有发言权。
  • 选 A（名言对号错位）：名言本身没错，错在主题不合——它回答「理论为什么有力量」，不是「怎样认识实际」。
  • 选 B（被「反对……」的否定句式迷惑）：调查研究确实反对主观主义，但选项把矛头错指「经验主义、尾巴主义、机会主义」的组合，且只讲「破」，不答题干要的「立」。
记忆锚点：解剖麻雀＝典型调查＝由个别到一般＝从中国实际中找中国革命的规律；没有调查就没有发言权。

第 0 步：先立机制——马克思这句话在说什么结构

"没有无义务的权利，也没有无权利的义务"，说的是权利与义务的结构对应关系：你享有权利，必有人履行相应义务；你履行义务，正是他人享有权利的保障。据此，教材把法律权利与法律义务的关系概括为三层：

  1. 相互依存：法律权利的实现必须以相应法律义务的履行为条件；法律义务的履行必须以法律权利的享有为依据——权利的存在与发展同样以义务的存在与发展为条件；
  2. 目的与手段：对具体主体而言，权利是目的、义务是手段，二者总是相互关联；
  3. 复合性：有些法律权利和法律义务是复合的——一个行为既是权利又是义务（如劳动、受教育）。

注意第 3 层的量词："有些"——这就是排除 B 的钥匙；第 1 层的"互为条件"——这就是选 C、D 的依据。

第 1 步：C 对——权利的实现以义务的履行为条件

财产权的实现以他人负有不侵犯财产的义务为条件；诉权的实现以法院负有受理与裁判义务为条件。抽掉对应的义务，权利只是纸面宣示——这正是"没有无权利的义务"的具体化。

第 2 步：D 对——权利的存在与发展以义务的存在和发展为条件

不止"实现"这一层：连权利的存在和发展都要以义务的存在和发展为条件——义务范围随时代扩展（如环境保护义务），才支撑起新型权利（环境权益）的成立与发展。义务是权利的地基，这就是引文里"没有无义务的权利"的结构含义。

第 3 步：A 为什么错——"离开权利仍有价值"斩断依存

A 说法律义务离开法律权利"仍然有履行的价值"。这与引文正面对撞：没有无权利的义务——义务的正当性来自权利结构，脱离权利谈义务，只剩单纯的强制，恰恰是法治思维要摆脱的义务本位旧观念。A 割裂了相互依存关系。

第 4 步：B 为什么错——"所有……都复合"把特称说成全称

第（1）问：技术构成与价值构成是什么关系、朝哪里变

机制层：先分清两种构成。 同一笔资本可以从两个角度观察：

  • 技术构成——从实物量（物质形态）看：生产资料的量与劳动力的量的比例。这个比例由生产技术水平决定：技术越先进，一个工人同一时间能推动的生产资料越多，"人手一台机器"会变成"一人看管一排机器"；

毛中特·习思想材料题。材料是二十届四中全会《十五五规划建议》：明确"十五五"时期是基本实现社会主义现代化"夯实基础、全面发力的关键时期"，发展环境"战略机遇和风险挑战并存、不确定难预料因素增多"。第（1）问 5 分答"为什么强调做强国内大循环、畅通国内国际双循环"，第（2）问 5 分答"为什么把共同富裕迈出坚实步伐作为总体性要求"。

第（1）问：为什么强调做强国内大循环、畅通国内国际双循环

机制层：循环的确定性从哪里来。 新发展格局＝以国内大循环为主体、国内国际双循环相互促进。它不是一句口号，而是对"形势倒逼＋家底支撑"的回应：

  • 形势倒逼——"十五五"时期发展环境深刻复杂变化，不确定难预料因素增多：外部需求、供给链条随时可能被扰动。外部环境越不确定，越需要用国内大循环的确定性去对冲外部环境的不确定性，把发展主动权牢牢掌握在自己手中（材料：集中力量办好自己的事）；
  • 家底支撑——我国经济基础稳、优势多、韧性强、潜能大，其中与循环直接相关的是超大规模市场优势与完整产业体系优势。做强国内大循环，就是充分发挥这两大优势：扩大内需、畅通生产—分配—流通—消费各环节，增强经济韧性和自主性——这是"做强"二字的落点；
  • 双循环相互促进——国内循环不是关起门来的循环。畅通国内国际双循环，以高水平对外开放促进要素流动和互利合作，用好国内国际两个市场、两种资源，在开放中提升国内循环的质量和效率；
  • 统筹发展与安全——大国经济的回旋余地大，国内循环越强，抵御外部冲击的能力越强，从而实现高质量发展与高水平安全的统筹。

边界澄清（参考答案特意强调的坑）。 强调国内大循环为主体，绝不能理解为封闭运行：新发展格局不是封闭的国内循环，而是开放的国内国际双循环。答成"以内循环取代外循环""关起门来自己干"，就偏离了"双循环相互促进"的本意。

第（2）问：为什么把共同富裕"迈出坚实步伐"作为总体性要求

机制层：定位决定覆盖面。 共同富裕被写进指导思想并称"总体性要求"，根源在它的三重定位：

  • 本质定位——共同富裕是社会主义的本质要求，是中国式现代化的重要特征。社会主义与资本主义现代化道路的区别，正在于发展成果为谁享有；
  • 价值立场——共同富裕体现以人民为中心的发展思想：发展的目的是满足人民日益增长的美好生活需要、促进人的全面发展，而不是为增长而增长；
  • "总体性"的含义——它不是某一领域、某一阶段的局部任务，而是贯穿"十五五"经济社会发展全过程各方面的要求：推动经济实现质的有效提升和量的合理增长，最终都要落到"人的全面发展、全体人民共同富裕迈出坚实步伐"上——所以材料说它是"指导十五五时期社会经济社会发展的一个总体性要求"。

怎么迈出坚实步伐。 在高质量发展中保障和改善民生：提高公共服务和分配的公平程度，缩小城乡、区域、收入差距，扎实地把民生短板补上来，促进全体人民共同富裕取得实质性进展。

预判追问：为什么是"迈出坚实步伐"而不是"实现共同富裕"？ 材料点明"实现社会主义现代化是一个阶梯式递进、不断发展进步的历史过程"——共同富裕不可能一步到位，"十五五"正处在基本实现社会主义现代化"夯实基础、全面发力"的关键期，故定位为阶段性目标：迈出坚实步伐、取得实质性进展。这也顺带划清了边界：共同富裕不是同步富裕、不是平均主义，要分阶段促进。

  • 只说"崛起"不说途径：南南合作、参与多边机制、争取代表性和发言权是三个具体影响途径，只写"力量壮大了"等于没有回答"如何影响"。
记忆锚点：同舟共济讲命运与共，天下为公讲共商共建共享，和而不同讲文明互鉴——舵锚楫帆是主张，巨轮是命运共同体。第三世界先登台反霸权，全球南方再崛起促多极，南南合作争发言，治理体系改公平。
