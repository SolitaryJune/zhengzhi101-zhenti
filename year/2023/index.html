联系与发展

答案：A

1

本题讲解：为什么"历史是最好的教科书"——历史、现实、未来的相通性

答案：A（历史、现实、未来是相通的）。

第 0 步：把序言的三句话拆成一条逻辑线

材料不是抒情段落，是三步论证：第一句"修史立典，存史启智，以文化人……延续几千年的传统"——说明修史这件事本身有意义；第二句"述录先人的开拓，启迪来者的奋斗"——给出修史的目的：前半句面向历史（述录先人），后半句面向未来（启迪来者），动手编纂的是当下的现实实践；第三句"一切向前走，都不能忘记走过的过去"——把"向前走（未来）"与"走过的过去（历史）"直接连起来。三句读完，考点浮出水面：历史、现实、未来三者是什么关系。

第 1 步：立机制——"相通"到底通在哪

相通有两层：时间上连续——未来从现实走来，现实从历史走来，谁也不是凭空出现；内容上继承发展——历史的经验教训沉淀为"教科书"，被今天的人读取、用于开创明天（"启迪来者的奋斗"）。所以"以史为鉴"能够成立，依据正是历史、现实、未来相互贯通：历史能认识今天、启迪明天。但要注意分寸：相通指的是联系与贯通，不是相同与重演——参考解析专门提醒"不能把相通理解成完全相同或完整重复"。

第 2 步：预判追问——"以史为鉴"会不会就是"一切历史都是当代史"？

不会，两者立场相反。"以史为鉴"的前提是历史有客观内容：先人的开拓被如实述录（《复兴文库》是对重要思想文献的客观选编），今天的人从中读取真实存在过的经验。而克罗齐"一切历史都是当代史"把历史说成当代人按主观需要重构的产物，否认历史的客观性——历史只成了当代心灵的一面镜子。一个立足客观经验，一个立足主观重构，恰好对立。

第 3 步：逐项对号入座

选项判断对应题干位置
A 历史、现实、未来是相通的✅"述录先人的开拓，启迪来者的奋斗"+"向前走不能忘记走过的过去"，逐句对应
B 一切历史都是当代史❌克罗齐命题，否认历史客观性，与序言立场相反
C 历史过程不包含任何偶然的因素❌历史是必然性与偶然性的统一，偶然因素真实存在
D 历史事件往往可以完整重复和再现❌历史事件不可完整重演；"相通"≠"相同"

易错点：每个干扰项对应哪种误解

  • 误选 B：把"历史服务当下"直接等价成"历史就是当代史"。序言说历史对当下有用（教科书），没有说历史丧失客观性、随当代人改写；B 是唯心史学观，见到就排除。
  • 误选 C：把"历史有规律"绝对化成"历史只有必然"。唯物史观讲必然性通过大量偶然性开辟道路——历史人物的个性、突发事件都是历史过程的真实组成；"不包含任何偶然因素"这种全称否定表述本身就是危险信号。
  • 误选 D：把社会形态更替中某些发展阶段的大体相似，误读成"历史事件完整重复和再现"。社会发展有相似"一幕"重演，但事件本身不可复制；选 D 恰恰是把 A 的"相通"偷换成了"重复"。
记忆锚点：历史、现实、未来 = 相通而不同一——连续、继承、借鉴，但不是相同、不是重演；"一切历史都是当代史"（否认客观性）与"历史不含偶然"（否认偶然性）都是绝对化谬误，见到即排。

答案：C（经济基础特别是生产关系的性质）。

第 0 步：先立机制——"骨骼定名"模型

题干已把定义递到手上：社会形态是"同生产力发展一定阶段相适应的经济基础同上层建筑的统一体"。这个统一体像一座建筑：经济基础是骨骼（一个社会占主导地位的生产关系的总和），上层建筑是皮肤（政体、法律、观念形态）。给社会形态定性质、起名字的，只能是骨骼——因为生产关系的核心是生产资料归谁占有，占有关系的类型一换，社会的名字就跟着换：

占主导的生产关系（骨骼）社会形态名
奴隶主占有生产资料和奴隶本身奴隶社会
地主阶级占有土地、剥削农民封建社会
资本家占有生产资料、雇佣劳动资本主义社会
生产资料公有制共产主义社会（社会主义是第一阶段）

所以五种社会形态的划分依据是经济基础特别是生产关系的性质。皮肤（上层建筑）千姿百态都不换名：同样是资本主义社会，政体可以是君主立宪也可以是共和制——形态名不变。

第 1 步：预判追问——为什么不是生产力（生产工具）？

最容易纠结的是 A。要分清两个层次：生产力决定形态的演变——生产力变了，旧生产关系迟早被撑破、新形态迟早出现，这是"决定"意义上的动力；但生产力不直接给形态命名——同样的机器大工业，配资本主义生产关系才叫资本主义社会，而不叫"机器社会"。按生产工具划出的石器/青铜/铁器时代，是技术文明分期，测量的是"先进/落后"，回答的不是"这是什么社会"。马克思讲"各种经济时代的区别在于怎样生产、用什么劳动资料生产"，说的是经济时代的技术测量器，与社会形态的定性标准是两句话，层次不同、并不矛盾。

A 生产工具的质量和数量❌是生产力发展水平的客观尺度，划出的是技术分期，不定形态之名
B 统治集团的阶级和政治属性❌属上层建筑；其阶级属性本身由生产关系决定——拿被决定的结果当依据
C 经济基础特别是生产关系的性质✅骨骼定名：占有关系换类型，形态才换名
D 人们社会交往和分工的范围和水平❌描述交往分工的发展水平，不是形态质态的划分标准

  • 误选 A：把"劳动资料是生产力水平的测量器"扩大成"社会形态的划分标准"。测量先进落后的是工具，给社会定名的是生产关系——测量器 ≠ 命名者。
  • 误选 B：觉得"奴隶主国家、地主国家、资产阶级国家"听起来就像形态名。注意因果方向：正因为生产关系是奴隶制，奴隶主阶级才成为统治集团——B 是被决定的表现；而且政体（君主制/共和制）变了形态名也不变，上层建筑属性更当不了依据。
  • 误选 D：把"交往形式"视角当成五形态标准。交往与分工是说明历史演进动力的一个视角（马克思早期著作中用过"交往形式"概念），但它回答"联系有多广、分工有多细"，回答不了"这是什么性质的社会"。
记忆锚点：社会形态 = 经济基础（骨骼）+ 上层建筑（皮肤）；骨骼（生产关系性质）定名，皮肤不换名；生产工具测水平、生产关系定性质——测量器与命名者分开记。

答案

答案：C

3

本题讲解：生产力变化改变什么——价值总量不动，单位价值量反比

答案：C（影响同一劳动在同样的时间内生产的单个商品价值量）。

第 0 步：先立机制——两种劳动、两个量

这段《资本论》引文是政治经济学里"劳动生产率与商品价值量"考点最直接的出处。钥匙在于分清两个量、两条来源：

  • 价值总量：价值是凝结在商品中的抽象劳动，量的唯一尺度是劳动时间。"同一劳动在同样的时间内"——支出的劳动量没变，凝结的抽象劳动量就没变，所以价值总量是常量，与生产力怎么变无关（引文第一句原话）。
  • 使用价值量（商品数量）：使用价值是具体劳动的产物，具体劳动的效率随生产条件变化。生产力提高，同样时间"提供的使用价值量就多些"；降低，就少些（引文第二句原话）。

一个量被"锁死"，另一个量在变——这正是题目设问的全部机关。

第 1 步：数值推演——单个商品价值量怎么被"摊薄"

单个商品的价值量 = 同一时间提供的价值总量 ÷ 同一时间生产的商品数量。分子是常量、分母是变量，结果自然反比变化。设 8 小时劳动创造的价值总量为 8（以小时计）：

情形价值总量（分子）产量（分母）单个商品价值量
生产力提高前816 件8÷16 = 0.5
生产力提高后824 件8÷24 ≈ 0.33

总量纹丝不动，产量变多，每件商品摊到的价值量下降——这就是"商品价值量与劳动生产率成反比"这一结论的来源，也直接命中 C：生产力的变化影响单个商品价值量。

第 2 步：逐项对号入座

选项判断对号理由
A 不影响商品数量❌引文原话：生产力提高时使用价值量"就多些"——数量恰恰受影响
B 不改变生产效率❌生产力的变化正表现为劳动生产率（效率）的变化，两者说的是一回事
C 影响单个商品价值量✅总量不变、数量变 → 单位价值量反比变化
D 改变价值总量❌引文原话："价值量总是相同的"——总量不随生产力变化

易错点：每个干扰项对应哪种误解

  • 误选 A：把"价值量不变"扩大化成"什么都不变"。不变的是价值总量（抽象劳动的凝结），变的是使用价值量（具体劳动的效率）——两个量、两条来源，混为一谈就选错。
  • 误选 B：没看出"生产力的变化"与"劳动生产率的变化"是同一件事的两种说法：机器更好、工艺更先进，就是效率本身在变。
  • 误选 D：以为"生产得快了，创造的价值也多了"。错在把使用价值（数量）的增长当成价值（抽象劳动凝结）的增长：价值的实体是劳动，劳动量没变，总量就不变；多出来的只是产品件数。
  • 反向混淆：还有人把关系记反，以为生产率越高单个商品价值量越大。记住摊薄模型：同样的价值馅，分的份数越多，每份越小。
记忆锚点：生产率变化 = 分子（价值总量）锁死、分母（件数）在变 → 单个商品价值量与劳动生产率成反比；"价值"跟抽象劳动走、"数量"跟具体劳动走——先分清两个量，再套摊薄公式。

垄断利润与成本价格
1 分

垄断组织通过制定垄断价格来获得垄断利润。在市场交易过程中，垄断组织获利高低实际上受到很多因素的影响。为了避免遭受净亏损，垄断组织所能接受的最低价格是

答案

答案：A

4

本题讲解：垄断定价的两条线——低于成本价格才叫净亏损

答案：A（成本价格）。

第 0 步：先立机制——三个价格概念摆上桌

垄断组织靠垄断价格获利：卖货用垄断高价（价值以上卖出），进货用垄断低价（价值以下买进），两头夹出垄断利润。要把"最低能接受什么价"问清楚，先摆出三个价格台阶：

价格构成含义
成本价格c + v（垫付的不变资本 + 可变资本）收回本钱的线
生产价格成本价格 + 平均利润自由竞争阶段利润率平均化后的"正常利润线"
垄断价格成本价格 + 垄断利润垄断组织"想卖"的价位

第 1 步：数值推演——价格被压到哪一条线才算"净亏损"

设垫付成本 c + v = 100，平均利润 = 20，垄断利润 = 50，则成本价格 = 100、生产价格 = 120、垄断价格 = 150。市场交易中获利高低受竞争、供需等因素影响，卖价可能被从 150 一路压下来：

卖价处境判断
150赚足垄断利润最理想
130低于垄断价、高于生产价格照样赚
110低于生产价格（平均利润拿不满）少赚，不亏——本钱 100 已收回
95低于成本价格净亏损——连本钱都收不回

分界清清楚楚：卖价只要 ≥ 100，成本已补偿，至多少赚；卖价 < 100，垫付的 c + v 都收不回，才叫净亏损。所以"避免净亏损"的最低可接受价 = 成本价格。

第 2 步：预判追问——为什么"低于生产价格"不算亏？

这是本题最大的陷阱。生产价格 = 成本价格 + 平均利润，平均利润是自由竞争阶段资本家按资本量分得的"正常份额"。低于平均利润只是赚得比"正常份额"少，本钱并没有折损——少赚 ≠ 亏损。两条线的位置关系：生产价格 = 成本价格 + 平均利润 > 成本价格，生死线永远在正常利润线下面。把"低于平均利润"误当成"亏损"，就会掉进 B。

第 3 步：逐项对号入座

选项判断理由
A 成本价格✅c + v 的补偿线；低于它才净亏损，是"最低可接受价"
B 生产价格❌正常利润线；低于它但高于成本价只是少赚
C 垄断低价❌垄断组织买进时压价的手段，不是卖出时的底线
D 垄断高价❌垄断组织卖出时抬价的手段，与"最低接受价"方向相反

易错点：每个干扰项对应哪种误解

  • 误选 B：混淆"利润为零的界线"（成本价格）与"利润低于平均水平的界线"（生产价格）。把自由竞争阶段的平均利润当成垄断阶段"不亏"的前提——实际垄断组织获利"高低受很多因素影响"，跌破平均利润完全可能也完全可以接受。
  • 误选 C / 误选 D：把"获利手段"当"价格底线"。垄断低价是进货时把买价压到价值以下、垄断高价是出货时把卖价抬到价值以上，都是"往有利方向使劲"的手段；题目问的是"最低能接受什么"，问的是底线，不是手段。
  • 概念回退：还有人用"平均利润率下降""竞争失败"等枝节解释，忘了题眼只在"避免净亏损"四个字——净亏损的定义就是收不回成本价格。
记忆锚点：两条线——成本价格 = 生死线（c + v，低于它才净亏损），生产价格 = 正常利润线（低于它只是少赚）；垄断高价/低价是手段，成本价格是底线——手段与底线分开记。

第 0 步：先立机制——"是什么社会"由经济制度说了算

第 1 步：预判追问——为什么政治制度确立（1954）不算标志？

有人会问：人民代表大会制度 1954 年就确立了，政治层面都到位了，为什么还不算"进入社会主义"？因为上层建筑的进展替代不了经济基础的定性：1954 年时，农业、手工业仍是私有制，资本主义工商业还在改造之中——政治制度再完善，只要私有制还是主体，社会就仍处在过渡时期（新民主主义社会）。反过来，1956 年三大改造一完成、公有制占了主体，社会性质立刻改变——"定名分"的开关装在经济制度上，这就是 A 不能选而 B 能选的原理依据。

第 0 步：先立机制——评价的对象是「价值关系」，不是客体本身

认识有两类：事实认识回答对象「是什么、怎么样」；价值评价回答对象「对主体有什么意义」。评价的对象不是客体本身，而是主客体之间的价值关系——即客体属性与主体需要之间的关系。这一条机制推出两条规则：

本题讲解：平均利润——判据只有一条：是否参与利润率平均化

答案：ABC。

第 0 步：先立机制——利润率是怎么被「拉平」的

不同生产部门的资本有机构成、周转速度不同，等量资本的利润率本来高低不等。但资本的本性是逐利：利润率低的部门把资本抽走，涌向利润率高的部门——部门之间的竞争、资本的自由转移持续进行，各部门利润率趋于平均，形成平均利润率。此后等量资本取得等量利润：利润不再等于本部门工人创造的剩余价值，而是按资本量从社会总剩余价值中分得的一份——剩余价值在资本家集团内部按资再分配。

由此得出本题唯一的判据：一份资本能否获得平均利润，看它是否参与了利润率平均化过程——即它是不是投入生产或流通中实际发挥作用的职能资本，能否在部门间转移、参与剩余价值的再分配。

第 1 步：逐项对号入座

B 农业资本✅农业资本同样是职能资本，参加利润率平均化，获得平均利润
C 商业资本✅从产业资本中独立出来、投入流通领域的职能资本，参与剩余价值分配，按等量资本获平均利润（商业利润）

第 2 步：借贷资本为什么「不入场」

借贷资本是所有权与使用权分离的资本形态：它把货币资本贷给职能资本家（产业资本家、商业资本家）使用，自己不直接经营生产和流通。职能资本家取得的平均利润要一分为二：一份作为利息付给借贷资本家，一份作为企业利润留给自己。利息的「封顶线」就是平均利润——借贷资本家拿的是平均利润的一部分，而不是平均利润本身。这正说明它站在平均化过程之外：平均利润在职能资本家手里形成之后，才被切出一块付给它。

追问一步：农业资本为什么不是「特殊分子」

有人以为土地被垄断，农业就不参加平均化。实际机制是：农业资本投入生产，照样参与部门竞争与利润率平均化，平均利润部分照拿；土地私有权的垄断拦下的只是农业中超过平均利润的超额利润，把它转化为地租交给土地所有者。「特殊」的是超额利润的去向，不是平均利润的有无——漏掉 B 的误解就在这里。

  • 漏选 B（误选 AC）：以为农业因土地垄断而「特殊」、不参加平均化——垄断只改变超额利润的去向（转地租），不改变农业资本获得平均利润的事实。
  • 漏选 C（只认产业）：把平均利润只和生产挂钩——商业资本虽不生产剩余价值，却参与剩余价值的分配，按职能资本的身份分得平均利润。
记忆锚点：入场券 = 职能资本（产业、农业、商业）拿平均利润；借贷资本两权分离、不入场，拿利息——平均利润的一部分。

  2. 全球性挑战层层加码：不平等问题愈发严重、世界逐渐走向分裂；粮食、能源危机对发展中经济体冲击最大——和平赤字、发展赤字、安全赤字、治理赤字突出。
  3. 两种选择摆在面前：是合作还是对抗、团结还是分裂、包容还是排他——世界又一次站在何去何从的关口，"何去何从取决于各国人民的抉择"。
  4. 主流判断不能丢：尽管挑战空前，和平、发展、合作、共赢的时代潮流没有改变，这既是绝大多数国家的共同愿望，也是"十字路口"仍有正确方向的依据。

预判追问：挑战这么严峻，为什么说时代潮流没有变？ 因为"十字路口"的判断本身是两面结构：分裂对抗的逆流确实抬头，但它违背大多数国家求和平、谋发展、促合作的共同愿望——逆流不等于主流；同时中国的行动（材料2）证明合作共赢不仅必要而且可行——潮流由大多数国家的意志和实践决定，不由个别国家的大国竞争冲动决定。只答"危机深重"不答"潮流未变"，形势判断就失衡了。
