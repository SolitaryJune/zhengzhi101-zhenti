zz-2010-01

人的自由全面发展
1 分

1884年1月3日，意大利人卡内帕给恩格斯写信，请求他为即将在日内瓦出版的《新纪元》周刊的创刊号题词，而且要求尽量用简短的字句来表述未来的社会主义纪元的基本思想，以区别于伟大诗人但丁对旧纪元所作的“一些人统治，另一些人受苦难”的界定。恩格斯回答说，除了从《共产党宣言》中摘出下面一段话外，再也找不出合适的了，这就是：“代替那存在着阶级和阶级对立的资产阶级旧社会的，将是这样一个联合体，在那里，每个人的自由发展是一切人的自由发展的条件。”这段话表明，马克思主义追求的根本价值目标是：

答案

答案：A

1

本题讲解：马克思主义的根本价值目标——每个人自由而全面的发展

答案：A。

第 0 步：先立住背景——恩格斯这道"命题作文"的题眼

1884 年卡内帕请恩格斯用最简短的字句概括"未来社会主义纪元的基本思想"，并要求与但丁"一些人统治，另一些人受苦难"的旧纪元界定相对照。恩格斯从《共产党宣言》只挑出一句："代替那存在着阶级和阶级对立的资产阶级旧社会的，将是这样一个联合体，在那里，每个人的自由发展是一切人的自由发展的条件。"

抓两个词："代替"——新社会取代阶级对立的旧社会；"联合体"——自由人联合体。这句话就是共产主义的价值目标：人的自由而全面的发展。

对号入座：为什么是 A

  • 马克思主义对未来社会的设想不描绘乌托邦式细节，而是锁定根本方向：消灭阶级对立之后，社会发展的落脚点是每个人（个体）与一切人（全体）的自由发展相统一。A 项正是题干引文的同义转述，且与"每个人的自由发展是一切人的自由发展的条件"逐字对应。

为什么错：三个干扰项各对应什么误解

  • B（人类永恒不变的普适价值）：把马克思主义说成抽象"普适价值"是典型误解。马克思主义的价值目标建立在现实社会发展条件上，是历史的、具体的，不存在"永恒不变"的价值许诺——这正是它与抽象人道主义的分界线。
  • C（四海之内皆兄弟的大同世界）：这是中国传统的大同理想，属于朴素、空想的愿景，没有阶级分析与实现路径，与科学社会主义不是一回事。
  • D（自由、平等、博爱的理性王国）：这是启蒙运动的旗帜、资产阶级革命的目标；空想社会主义也停留在"理性王国"式的道德呼吁上。恩格斯特意不选这类表述，就是要同它们划清界限。

预判追问

  • 为什么恩格斯说"再也找不出合适的了"？ 因为《共产党宣言》这句话同时点明了两件事：新社会的价值目标（自由发展）与实现条件（代替阶级对立的旧社会）——目标与道路在同一句话里，这是马克思主义区别于一切空想的地方。
  • "每个人"与"一切人"什么关系？ 个体发展与全体发展互为条件，不是先后割裂的两步；题干强调"每个人的自由发展是一切人的自由发展的条件"。
记忆锚点：马克思主义根本价值目标 = 人的自由而全面的发展（自由人联合体）；凡见"普适价值""大同世界""理性王国"，都是抽象/空想/旧纪元的帽子。

zz-2010-02

量变与质变
1 分

有一则箴言：“在溪水和岩石的斗争中，胜利的总是溪水，不是因为力量，而是因为坚持。”“坚持就是胜利”的哲理在于：

答案

答案：C

2

本题讲解："坚持就是胜利"——量变积累引起质变

答案：C。

第 0 步：把寓言翻译成哲学语言

"溪水 vs 岩石"：论力量（单次冲击的强度），水输给石；论结果，水赢。赢在"坚持"——一次冲刷微不足道，但日复一日的同方向作用不断积累，最终改变岩石的形态。

哲学翻译：每次冲刷是量变（数量增减、程度的深化），岩石最终被冲开磨圆是质变（根本性质/形态的变化）。"坚持就是胜利"的哲理 = 量变积累到一定程度必然引起质变。

为什么是 C：题干限定了唯一对口原理

  • 题干关键词是"不是因为力量，而是因为坚持"——排除"单次强度"，突出"持续积累"。四个选项中只有 C 讲"量的积累 → 质变"这条线。
  • 严谨表述是"量变达到一定程度必然引起质变"：量变是质变的必要准备，质变是量变的必然结果。选项 C 是当年考点的简写，方向正确；理解时要带上"度"这个条件，不能误读成"一动就变"。

为什么错：三个干扰项各对应什么误解

  • A（必然性通过偶然性开辟道路）：讲必然与偶然的关系。溪水冲刷岩石是反复进行的必然过程，题干恰恰强调不靠运气、偶然——与 A 方向相反。
  • B（肯定中包含着否定的因素）：讲辩证否定观（事物的自我否定）。岩石不是自己否定自己，而是被持续的外部作用改变——题干没有"内部自我否定"的意思。
  • D（有其因必有其果）：讲因果联系的客观性。题干问"坚持为什么会胜利"（变化如何发生），不是"结果背后有没有原因"——D 答非所问。

预判追问

  • 量变一定引起质变吗？ 未达到"度"的范围内的量变不改变事物性质；"度"是保持事物质的稳定性的数量界限。背原理别丢"达到一定程度"。
  • "水滴石穿"为什么不选外因？ 外因通过内因起作用，但题干问的是"坚持（量的积累）"与"胜利（质变）"的联系，不涉及内外因框架。
记忆锚点：坚持 = 量的积累；胜利 = 质变；"不是力量，而是坚持" → 量变达到一定程度必然引起质变。

zz-2010-03

人与自然的关系
1 分

右边这张照片反映出由于气候变暖，北极冰盖融化，致使北极熊无处可去的场景，颇具震撼力。它给我们地球上的人类发出的警示是：

答案

答案：D

3

本题讲解：北极熊照片的警示——人与自然的关系怎么定位

答案：D。

第 0 步：先立机制——人与自然通过"实践"绑定，出问题先看人的活动

人与自然不是邻居关系，而是被实践（首先是物质生产实践）拴在一起的关系：人改造自然获取生活资料，改造活动的成果与代价都会沿同一条纽带反馈回来。改造尊重自然规律，自然供给资源、容纳排放；改造违背自然规律（过度排放、滥伐滥捕），自然就把失衡的账单原样退回——冰盖融化、北极熊无处可去，就是这张账单的实物照片。所以看到"自然出问题"，机制上第一怀疑对象是人类自身活动，而不是自然自己。

再给"自然地理环境"在社会历史观里定位，这是一张三级表：

地位能力边界典型措辞
社会存在与发展的必要条件能加速或延缓社会发展"影响""前提""重要条件"
不是根本决定力量不能决定社会的性质与走向决定力量的帽子属于物质生产方式
自身运行有规律规律是客观的，可以被认识和利用"尊重规律""可持续发展"

题干的警示落点只能落在第一行、第三行允许的措辞上——这正是 D 项"生态环境已日益成为人类反思自身活动的重要前提"：对象是人（反思"自身活动"），分寸是"重要前提"（不越位成决定力量）。

第 1 步：三个干扰项各踩了机制的哪条红线

  • A（人与自然的关系成为人与人一切社会关系的核心）→ 顶替了不该顶替的东西：人与人一切社会关系的核心是生产关系（利益关系）。人与自然的关系再紧迫，也处在"人—自然"这层，取代不了"人—人"层的核心。"一切……核心"是顶替式过头话。
  • B（生态失衡已成为自然界自身周期演化不可逆转的趋势）→ 归因错位 + 绝对化双重踩线：第一错把账记错了对象——机制上失衡主要源于人类不合理活动，不是"自然界自身周期演化"；第二错"不可逆转"把客观规律理解成死局——规律既然可以被认识和利用，治理修复就能缓解乃至扭转。
  • C（自然地理环境已成为人类社会发展的根本决定力量）→ 地理环境决定论：这是第 0 步表格里明令禁止的第二行——"决定"的帽子只能给物质生产方式，给地理环境就是教科书级错误。

预判追问

  • 为什么 D 的措辞"安全"？ 它只把生态环境放在"反思的前提"位置：前提是起点，不是终点，更不是主宰——既不夸大（对 A、C 的克制），也不否认人的责任（对 B 的纠正）。
  • 这类图片题怎么秒判？ 先问"照片控诉谁"。控诉人 → 选指向"反思人的活动、尊重规律"的选项；凡是把话说满的（"一切""根本决定""不可逆转"）先存疑。
记忆锚点：北极熊照 → 控诉人类自身活动；地理环境 = 必要条件 + 影响因素，"决定""核心""不可逆"三个词一出现就排除。

zz-2010-04

劳动力商品与剩余价值
1 分

劳动力成为商品是货币转化为资本的前提条件，这是因为：

答案

答案：C

4

本题讲解：劳动力成为商品——货币转化为资本的前提

答案：C。

第 0 步：先立机制——"前提"问的是增殖从哪来

货币变资本，中间必须多出一个增殖额。把两条流通公式并排看：

公式内容价值走向问题
简单商品流通W—G—W为买而卖，价值量不变不产生增殖
资本流通G—W—G′，且 G′ = G + ΔG为卖而买，要求带回 ΔGΔG 从哪里来？

在流通领域找不到 ΔG 的来源：等价交换一分钱不生，贱买贵卖只是把别人口袋里的价值挪过来，社会总价值纹丝不动。所以增殖只能发生在货币买到的商品被使用的环节——也就是要求流通中存在一种"用起来能生钱"的特殊商品。劳动力正是这种商品：它的使用价值就是劳动本身，而劳动创造新价值，且能创造出大于劳动力自身价值的价值，超出部分就是剩余价值 ΔG。

这就是"前提"的准确含义：买到劳动力（货币所有者购买的劳动力能够带来剩余价值，即 C），货币才有可能完成 G—W—G′ 的增殖、从钱变成资本；没有这一步，G′ 永远等于 G。"前提"类设问，答案永远落在特殊使用价值 → 剩余价值这条链上。

第 1 步：三个干扰项各对应哪种误解

  • A（资本家购买的是劳动力的价值）→ 买卖对象说反：资本家按劳动力的价值付钱（工资），但买回来的是劳动力的使用价值（让它干活）。"前提"的要害从来不是"买了它的价值"，而是买回的东西在生产中"能创造"。把支付标准当成购买对象，就落进 A。
  • B（劳动力商品具有价值和使用价值）→ 拿共性当特性：一切商品都有价值和使用价值，这是普通商品和劳动力共有的属性，只能证明劳动力"是商品"，回答不了"为什么唯独它能带来增殖"。题问的是特殊性，B 给的是普遍性。
  • D（劳动力自身的价值能够在消费过程中转移到新的商品中去）→ 张冠李戴："价值转移"是生产资料（不变资本 c）的专职——机器折旧、原料消耗把自身价值原样搬进新产品。劳动力的价值不是被转移，而是被工人的活劳动再生产出来（工资那一块），并且额外多造出新价值（可变资本 v + 剩余价值 m）。D 把 c 的戏份安给了劳动力。

预判追问

  • 形式平等与剥削矛盾吗？ 不矛盾，反而要分两层看：流通环节按劳动力价值等价买卖（形式平等）；增殖发生在生产环节——劳动力特殊使用价值登场的地方。这正是"前提在购买、实现在使用"的分工。
  • 记哪张口诀？ 不变资本 c 转移价值；可变资本 v 再生产自身价值并带来剩余价值 m。见到"转移"想 c，见到"创造/增殖"想劳动力。
记忆锚点：劳动力 = 唯一"用起来能生钱"的商品；G—W—G′ 走通的前提 = 特殊使用价值带来剩余价值（C 型选项）；"转移价值"永远属于生产资料。

zz-2010-05

社会主义初级阶段主要矛盾
1 分

1981年党的十一届六中全会通过《关于建国以来党的若干历史问题的建议》对我国社会主要矛盾作了规范的表述：“社会主义改造完成以后，我国所要解决的主要矛盾，是人民日益增长的物质文化需要同落后的社会生产之间的矛盾。”我国社会主要矛盾的主要方面将长期是：

答案

答案：A

5

本题讲解：主要矛盾的主要方面——为什么落在"生产力落后"

答案：A。

第 0 步：先立机制——"主要矛盾、矛盾双方、主要方面"是三级结构

背表述不够，得先把层级立起来。1981 年十一届六中全会《关于建国以来党的若干历史问题的决议》给出的是主要矛盾这句话，它内部又拆出矛盾双方，双方地位不平衡，占支配地位的一面是主要方面，事物的性质主要由它决定：

层级内容本题对应
主要矛盾人民日益增长的物质文化需要 ↔ 落后的社会生产题干原文
矛盾双方一侧是"需要"（人民的物质文化需要），另一侧是"生产"（社会生产）排除 D 的依据
主要方面双方中占支配、决定矛盾性质的一面本题所问

主要矛盾的主要方面不是靠背出来的，而是用"症结—钥匙"法推出来的：这对矛盾为什么成立、为什么叫主要矛盾？症结在生产满足不了需要——落后的社会生产制约着人民需要的实现，矛盾的性质由"落后"这一侧决定；解决矛盾的钥匙也握在这一侧手里——大力发展生产力，把"落后"补上。谁决定性质、谁握钥匙，谁就是主要方面 → A（生产力落后）。

第 1 步：这个判断的政治经济学推论（互为印证）

正因为主要方面是"生产力落后"，党才顺理成章地推出"以经济建设为中心""发展才是硬道理"的路线——主要方面在哪里，工作重心就在哪里。这条因果链反过来验证了 A 的位置：如果主要方面是"需要"（D）或"发展要求"（B），重心就该落在"满足需要"而不是"发展生产"上，与整个初级阶段路线对不上。

第 2 步：三个干扰项各对应哪种误解

  • B（生产力不断发展的要求）→ 拿"药方"当"病症"：这是解决矛盾的努力方向，属于"钥匙"一侧，不是矛盾的症结本身；而且"落后的社会生产"这一表述里根本没有"不断发展"的成分。把改造方向当矛盾的主要方面，就选了 B。
  • C（经济文化发展不平衡）→ 层级错位：地区发展不平衡、城乡不平衡是初级阶段的结构性特征，挂在次要矛盾和具体领域层面，够不到"主要矛盾的主要方面"这个层级。
  • D（人民日益增长的物质文化需要）→ 主次摆反：这是矛盾的另一侧（需要侧）。需要是矛盾里的"压力"，生产（落后）才是"症结"；把压力侧当成主要方面，等于宣布矛盾的性质由需要决定、解决之道是抑制需要——方向恰好说反。

预判追问

  • 现在还这么答吗？ 注意口径分层：本题是 1981 年《历史决议》的表述，属十九大前的历史口径，2010 年考试按它作答；2017 年十九大已更新为"人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾"。两套表述都要记，答题先看题干给的年代。
  • 一般方法是什么？ 判主要方面就两问：矛盾的性质由谁决定？解决矛盾的钥匙在谁手里？两问指向同侧。
记忆锚点：需要 ↔ 生产，主次看症结——症结在"落后"，主要方面 = 生产力落后（1981 年口径）；十九大后口径已更新，做题先认年代。

zz-2010-06

发展的根本目的
1 分

“发展才是硬道理”、“发展是党执政兴国的第一要务”、“发展是解决中国一切问题的总钥匙”，这是对社会主义建设历史经验的深刻总结。中国解决所有问题的关键是要靠自己的发展，而发展的根本目的是：

答案

答案：D

6

本题讲解：发展的根本目的——共享发展成果，实现共同富裕

答案：D。

第 0 步：先立机制——"手段链"与"目的链"不能接错头

题干前半句一口气给了三个口号："发展才是硬道理""发展是党执政兴国的第一要务""发展是解决中国一切问题的总钥匙"——三个说法全部落在手段层：说的是"解决中国所有问题靠什么"，答案是"靠发展"。最后一问却拐了个弯：发展的根本目的——问的是"发展为了谁"。把这条链完整立起来：

环节内容题干对应
手段发展：做大"蛋糕"硬道理 / 第一要务 / 总钥匙
主体人民：发展为了谁、成果归谁设问"根本目的"指向的位置
目标共同富裕：分好"蛋糕"社会主义本质论的终点

社会主义生产的目的是满足人民日益增长的物质文化需要，发展成果由人民共享，最终走向共同富裕。问"根本目的"，链条必须接到目的端：D 项"使人民共享发展成果，实现共同富裕"正是这条链的终点站——主体（人民）和目标（共同富裕）一个不缺。

第 1 步：三个干扰项各对应哪种误解

  • A（增强综合国力）→ 把"中间收获"当"终点"：综合国力是发展的重要结果之一，也是"解决一切问题"的实力基础，但它属于国家层面的能力建设，本身还要回答"强大起来为了谁"——链条没接完，停在半路。
  • B（体现社会主义优越性）→ 把"表现"当"目的"：优越性是发展成果对制度的证明，是"发展得好会带来什么"，不是"发展为的什么"；为"显示优越"而发展是本末倒置。
  • C（消灭剥削，消除两极分化）→ 最强干扰：把"环节"当"终点"：C 确实在社会主义本质论五句话里——"解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕"。但看排列：前四句是手段与过程性要求，"最终达到"三字把目标收给共同富裕。C 是到达 D 的必经环节，问"根本目的 / 最终目标 / 落脚点"时，环节让位于终点。

预判追问

  • 本质论和这道题什么关系？ 本质论回答"什么是社会主义"，五句话分三层：解放和发展生产力是手段面，消灭剥削、消除两极分化是制度面，共同富裕是目标面。问"本质"→ 五句全要；问"根本目的 / 最终目标 / 出发点落脚点"→ 只取目标面。本题正是后者。
  • 怎么识别"目的"类设问？ 题眼信号："根本目的""最终""落脚点""为了谁""归宿"。而"总钥匙""第一要务""硬道理"是手段层信号——题干故意把它们铺在前半句，就是等你把手段误当答案。
记忆锚点：发展是手段、人民是主体、共同富裕是终点；本质论五句里只有"最终达到共同富裕"是目标面，C 是通往 D 的环节，别把环节当终点。

答案：A

7

本题讲解：建设资源节约型社会的核心——“核心”问的是本质，不是做法

答案：A。

第 0 步：先立机制——“两型社会”为什么是两个词，各管一段

题干出自十七大报告：坚持节约资源和保护环境的基本国策，把建设资源节约型、环境友好型社会放在工业化、现代化发展战略的突出位置。“资源节约型”与“环境友好型”不是同义反复，而是按资源流的两端分工：

概念管哪一端对立面关键词
资源节约型社会投入—消耗端：资源从哪来、用得省不省高消耗、低效率、大浪费节约、提效

题干只问资源节约型社会的核心——先把范围钉死在投入端，环保类举措一律不许混进来（这正是 B 的病根）。

第 1 步：先答掉最要紧的“为什么”——“核心”和“途径”差在哪一层

判断“核心”的标尺：核心 = 这个社会形态定义里少不了的本质要求；途径 = 通向它的某条具体做法。资源节约型社会的对立面是“高消耗、低效率、大浪费”，把这句话翻成正面要求，恰好两件事：省（节约使用资源）+ 效（提高能源资源利用效率）——A 项一手抓省、一手抓效，正是定义本身的展开，选 A。

为什么最强的干扰 D 不是核心？ 循环经济（减量化、再利用、资源化）确实是建设资源节约型社会的重要途径，但它是“怎么做到省和效”的一条路子，属于手段层；“核心”问的是“这个社会形态靠什么立住”，属于本质层。真题就爱考这一层差：见“核心 / 根本 / 本质”回定义里找，见“途径 / 抓手 / 措施”才轮到具体做法。

第 2 步：三个干扰项各对应哪种误解

  • B（加强节能减排和生态保护工作）：双重错位——①把“具体举措”当“核心”（层次错）；②“生态保护”属于环境友好型的范畴，答到了隔壁那型头上（范围错）。病根：把“两型”混为一谈。
  • C（限制能源资源的开发和利用）：把“节约”曲解成“少开发、不开发”，与工业化、现代化的发展要求直接对立。节约 ≠ 不用，而是高效开发、合理利用——C 是对“节约”最典型的字面化误解。
  • D（发展循环经济）：把“途径”拔高成“核心”。D 的内容本身没错，错的是它在这道题里的地位——内容正确 ≠ 是本题答案。

易错点

  • 见“循环经济”就选 → 误选 D：先看题问的是哪一层（核心还是途径），再对号入座。
  • 把环保举措混进节约型 → 误选 B：“两型”各管一段，生态环保归“友好型”。
  • 把节约理解为限制利用 → 误选 C：节约是“用得省、用得好”，不是“不让用”。
记忆锚点：资源节约型社会的核心 = 节约使用资源 + 提高能源资源利用效率（省 + 效）；循环经济是途径不是核心；生态环保归“友好型”。

1 分

随着经济的快速发展和物质生活水平的提高。人们的精神文化需求日益增长，迫切要求通过深化文化体制改革，激发文化发展的活力，为人民群众提供更多更好的文化产品和文化服务，保障人民的基本文化权益。保障人民基本文化权益的主要途径是：

答案

答案：C

8

本题讲解：保障人民基本文化权益的主要途径——“基本”靠事业，“多样”靠产业

答案：C。

第 0 步：先立机制——文化体制改革的“两分法”

深化文化体制改革，第一刀是按谁来主导、为谁服务把文化单位分成两类；这一分法就是本题四个选项的坐标系：

类别谁主导追求什么满足什么需求
公益性文化事业政府主导社会效益基本文化需求（保基本、兜底线、促公平）
经营性文化产业市场主导经济效益多样化、个性化需求

题眼是“基本文化权益”。基本权益的特点：人人平等享有，不能看“买不买得起”的脸色——而市场只为付得起钱的人服务，兜不住底线。顺着两分法找，答案只能落在政府主导的那一类。

第 1 步：对号入座——政府主导的那一类长什么样

政府主导、免费或低价、覆盖城乡的公共文化产品，组织起来就是公共文化服务体系：公共博物馆、图书馆、文化馆、农家书屋、广播电视村村通、农村电影放映……它们不靠门票、不挑消费者，承担的正是“保基本、兜底线”的功能。C 项“发展公益性事业，建立政府主导的公共文化体系”与机制一一对应：公益性事业是内容，公共文化服务体系是它的组织形式，选 C。

第 2 步：三个干扰项各坏在哪一层

  • A（繁荣社会主义文化，提高文化软实力）：这是文化建设的总体目标层，回答“文化强不强、软实力大不大”；题问的是“基本权益靠什么保障”的途径——层次错位，答非所问。
  • B（协调发展公益性文化事业，经营性文化产业）：表述本身没错，但它是文化体制改革的总体布局（两手抓、两手都要硬）；题干问的是“基本权益”的主要途径——主要靠的是公益性这一手，把两手并列当成保障途径，就答偏了。
  • D（调动社会力量在市场竞争中发展壮大文化事业）：双重张冠李戴——①在市场竞争中发展壮大的应是文化产业，“文化事业”恰恰由政府主导、不进市场搏杀；②拿市场竞争保“基本”，弱势群体、偏远地区会先被市场淘汰在外，兜不了底。

易错点

  • 把“基本”与“多样”混搭 → 误选 B：基本需求主要靠事业保障，多样化需求靠产业满足；两者是分工，不是并列担当。
  • “事业”“产业”关键词错位 → 误选 D：事业 = 公益 / 政府 / 社会效益，产业 = 经营 / 市场 / 经济效益，逐词锁定。
  • 被“软实力”等大词吸引 → 误选 A：目标层表述再漂亮，也替代不了“途径”这个问法。
记忆锚点：保基本找事业（政府主导的公共文化服务体系），多样化找产业（市场竞争）；A 是目标，B 是布局，D 张冠李戴。

  • 以为反思苏联 = 突破苏联模式 → 误选 D：反思是突破的前提，不等于已经突破。

名言匹配题的关键动作是翻译：把口语化的名言压成教材里的考点语言。这句话里「才智」＝才、「品格」＝德，「大多数人以为是才智成就了科学家，错了，是品格」＝成就事业的根本在德不在才。它给出的不是一个孤立的判断，而是一对关系：德与才谁主导？——德主导，才被主导。

由此立起一条硬标准：正确选项必须复现「德统领才」的结构。这条标准同时解释了为什么「提到品德」还不够——只讲品德单方面、没有「才」作对照的选项，这个结构搭不起来。

第 1 步：B 项逐字对上

B 项出自司马光《资治通鉴》：才者，德之资也；德者，才之帅也。两个字拆开看：

  • 资＝凭借：才是成就德、发挥作用的资源，才支撑德；
  • 帅＝统帅：德主导才的运用方向。

「帅」字与「是品格」完全同构：两句话共享同一个结构——德居主导，才居被主导。选 B。

第 2 步：三个干扰项各说了另一件事

选项出处实际主题为何不合
A 道虽迩，不行不至；事虽小，不为不成《荀子·修身》重实践、重行动讲「知与行」，没有「德与才」这对关系
C 不学礼，无以立《论语·季氏》学礼立身只讲「礼」，缺「才」作对照项
D 是非之心，智也《孟子》界定「智」恰恰在强调才智，与题干方向相反

易错点

  • 见「科学家、才智」就选 D：D 恰恰在给「智」下定义，与「不是才智、是品格」方向相反——最典型的字面反应式错误。
  • 把「成就事业」读成「靠行动」而选 A：主题错位，A 是知行观，不是德才观。
  • 见「立身修养」就选 C：题干要的是德与才的关系，不是单方面修养。

预判追问

  • 德才关系完整口径：德解决「为谁服务、往哪走」，才解决「能不能做成事」；坚持德才兼备、以德为先。
  • 四个出处各管一件事：荀子讲「行」、孔子讲「礼」、孟子讲「智」、司马光讲「德才」，对号入座不混。
记忆锚点：品格成就科学家 ⇋ 「德者，才之帅也」；名言中「才与德」成对出现，认准「帅」字选 B。

  • A（爱国守法）：是二十字规范的第一条，爱国也是公民道德的首要要求——但「居首」不等于「重点」，两个定位词不能互换。
  • C（勤奋自强）：对应「勤俭自强」，是基本规范的一项内容，不是纲要点名的着力点。
  • D（团结友善）：同为基本规范内容，着眼人与人相处层面，不是「重点」。

1 分

我国宪法明确规定实行依法治国，建设社会主义法治国家。依法治国的根本要求是：

答案

答案：A

14

本题讲解：依法治国的根本要求——十六字方针

答案：A。

第 0 步：先立「法治运行链」，十六字是这条链的压缩

依法治国不是一句口号，而是一条环环相扣的运行链：法律从哪里来（立法）→ 人们是否按法办事（守法）→ 执法者是否严格（执法）→ 违法是否被追究（追责）。宪法确立「实行依法治国，建设社会主义法治国家」后，这条链被概括为依法治国的根本要求十六个字：

十六字环节地位
有法可依立法前提
有法必依守法中心环节
执法必严执法关键
违法必究追责保障

为什么它能当「根本要求」：四环覆盖法治全过程，且缺一即断——没有「可依」则无从守法，有法不依则立法落空，执法不严则守法失去强制后盾，违法不究则前面全部作废。

第 1 步：三个干扰项各对应什么概念

  • B（保障公民的知情权、参与权、表达权、监督权）：这是发展社会主义民主、保障公民「四权」的要求——回答「人民如何参与」，属民主建设维度，不是依法治国的要求清单。
  • C（立法公开、执法公开、司法公开）：「公开」是政务公开、司法公开层面的程序性原则，管透明度，层级低于「根本要求」，且漏掉了守法环节。
  • D（社会生活的法制化、规范化、民主化）：是对法治目标状态的描述，不是可操作的要求；「民主化」还混入了法治之外的维度。

归因一句话：B 换了维度（民主≠法治要求）、C 降了层级（程序原则≠根本要求）、D 改了性质（状态描述≠要求）。

易错点与预判追问

  • 十六字方针有新版本吗？ 有——党的十八大后提出「科学立法、严格执法、公正司法、全民守法」（法治建设新十六字方针）。本题按 2010 年考试口径问「依法治国的根本要求」，答旧十六字；两个「十六字」分开记，考场上别互换。
  • 对应关系口诀：立法—守法—执法—追责；前提—中心—关键—保障。
记忆锚点：根本要求＝有法可依（前提）、有法必依（中心环节）、执法必严（关键）、违法必究（保障）；新十六字「科学立法、严格执法、公正司法、全民守法」另记。

本题讲解：全球经济失衡的"根源"定位——南北发展严重不平衡

答案：D（南北发展严重不平衡）。

第 0 步：先立机制——讲话的三层结构与"等级词"定位法

胡锦涛 2009 年 9 月在 G20 匹兹堡峰会讲话《全力促进增长 推动平衡发展》谈全球经济失衡，内容分三层，一层比一层深：

层次内容对应选项
表现层（失衡"长什么样"）储蓄消费失衡、贸易收支失衡、世界财富分配失衡、资源拥有和消费失衡、国际货币体系失衡——五个"失衡"清单题干已给
原因层（失衡"经什么机制形成"）经济全球化与产业分工转移、现行国际经济体系与主要经济体宏观政策、各国消费文化和生活方式A、B、C
根源层（失衡"为什么根深蒂固"）南北发展严重不平衡——发达国家（北）与发展中国家（南）之间的发展鸿沟D

题干问"从根本上看，失衡的根源是"——"根源"是等级词，要的是最深层那一条。定位词一抓，先确定答案该在哪一层，再看选项各归属哪层。

第 1 步：为什么"根源"落在南北发展不平衡

  • 南方（发展中国家）在国际产业分工中处于低端、在资源定价与流动中处于不利位置、在国际货币体系中缺乏话语权——贸易失衡、财富分配失衡、货币体系失衡这些"表现"，都是从南北发展鸿沟这块土壤里长出来的。
  • 换句话说：A、B 说的那些机制之所以能持续起作用、失衡之所以反复出现，正因为南北差距摆在那里——它是其他一切失衡的深层土壤，所以讲话把"根源"给它。
  • 讲话的对策也印证这一点：促进平衡发展，要靠建立更公平的国际经济秩序、支持发展中国家发展——治"根源"就要治南北差距。

第 2 步：A、B、C 各错在哪一层

  • A（经济全球化深入发展、国际产业分工转移、国际资源流动）：定位在原因层。它们解释失衡"怎么传导、在哪里形成"，是背景与传导机制——但机制运行在结构之上，问"根源"还要再往下挖一层。
  • B（现行国际经济体系、主要经济体宏观经济政策）：定位在原因层，且最接近"制度原因"，迷惑性最强。但制度与政策属于可调整的操作层面（G20 协调的正是宏观政策）：调整它们能缓解失衡，却改不了失衡反复产生的土壤——够不着"根本"二字。
  • C（各国消费文化和生活方式）：次要的、习俗层面的因素，既非机制主体，更不是结构差距——离"根源"最远。

易错点：干扰项对应哪种误解

A 是全场最"正面"的选项——民族区域自治毫无疑问是处理民族问题的基本国策，没人会觉得它"错"。陷阱不在对错，在层次：题目问"原则"，A 给的是"制度"。做这类题先画层次线：问原则，制度不选；反过来问"基本政治制度／基本政策"，才轮到区域自治上场。同一个知识点，换一种问法答案就换一套，这正是命题人反复使用的手段。

本题讲解：洋务运动败在"三性"——病根与症状要分清

洋务运动（19 世纪 60—90 年代）的路线是：以"自强"为旗号办军事工业，以"求富"为旗号办民用工业，指导思想是"中学为体，西学为用"——在封建制度这个"体"不动的前提下，引进西方的器物技术。失败不是输在某一场战役，而是路线图本身就带着结构性硬伤："用"是从先进制度里长出来的技术，硬装进封建的"体"里必然变形。这就是 A"指导思想的封建性"——三性中的第一条，也是根子。三十多年经营，甲午战败宣告破产。

三处硬伤逐项对号

  • A 对：指导思想封建性——根子上的病：只想"补器物"，不触动封建制度；体用分裂，新生产力的"用"驮在旧制度的"体"上，注定两不对付。

  • C 错：资金人才的匮乏性——洋务企业确实常闹资金、人才饥荒，但缺钱缺人是经营中的困难与表现，不是教材所列失败的主要原因：真正的病根在制度（A）、命脉（B）、机体（D），不在钱袋。

为什么 C 不能选——"主要原因"问的是病根

题干的关键词是"主要原因"。判断标准：一个因素是病因还是症状，看它是制造其他困难的源头，还是被其他困难造成的结果。洋务企业的资金人才饥荒，恰恰是封建性（旧制度不产生近代积累）、依赖性（命脉在别人手里）酿出来的结果——它是症状，不是病根。教材对洋务运动失败原因的标准表述正是"三性"：封建性、依赖性、腐朽性，C 不在其中。把症状当病因，是"原因题"最常见的失分动作。

  • 误选 C：看到"资金匮乏"是史实就选——史实为真 ≠ 是主要原因；问病根不问症状。

  • 混淆层次：三性各有作用面——A 在路线（为什么注定失败）、B 在命脉（为什么做不大）、D 在机体（为什么做不好），合起来才是"主要"二字的完整分量。
记忆锚点：败在"体"（封建性）、"腿"（依赖性）、"庙"（管理腐朽）；缺钱缺人是症状，不是病根——"主要"原因只收三性。

第 0 步：先立机制——基本权利为什么按内容分格

宪法第二章把公民的基本权利按权利指向的对象分成几格存放：平等权；政治权利和自由；人身自由（人身自由、人格尊严、住宅、通信）；宗教信仰自由；社会经济权利（劳动权、休息权、物质帮助权）；文化教育权利；特定主体的权利保护。分格的根据不是"哪个更重要"，而是权利直接指向什么领域：政治权利和自由这一格，指向的是国家政治生活本身——公民以国家主人身份参与政治的那部分权利。

题干把这把尺子直接写在了题面上："作为国家政治生活主体依法享有的参加国家政治生活的权利和自由"。所以判每个选项，只问一句话：它是不是公民直接参与政治生活的权利？

件内容参与政治生活的方式

说话政治自由（言论、出版、集会、结社、游行、示威）表达政治意愿、参加政治活动的形式自由

  • A 对：选举权和被选举权——"选人"件，参加国家政治生活最基本的政治权利，稳稳落在这一格。
  • B 对：政治自由——"说话"件，六大政治自由都是表达政治意愿、参加政治生活的自由，同属这一格。
  • C 错：人身自由权——属于"人身自由"格，指向个人生活的人身安全与尊严，不指向政治生活。
  • D 错：宗教信仰自由权——属于信仰领域的独立一格，指向精神世界，与政治参与没有直接对应关系。

第 2 步：为什么 C、D 最有迷惑性（预判"为什么"）

  • C 的迷惑在"基础"二字：人身自由是行使其他一切权利的前提和基础——没有它，政治权利也无从谈起。考生容易把"很基础、很重要"错当成"很政治"。但"是前提"不等于"是本格"：它保障的是个人生活领域，分格看，它放在隔壁。
  • D 的迷惑在"话题"二字：宗教话题常出现在政治新闻里（国家管理宗教事务），但那是国家行为的一面；"信仰或不信仰宗教"是公民的精神生活自由，不是参加政治生活的权利。话题政治 ≠ 权利政治。

  • 把"前提"当"本格" → 多选 C：对应"重要 = 政治"的误解。判断口径只看权利指向的领域，不看重要性。
  • 把"政治自由"缩成"言论自由" → 漏选 B：政治自由是言论、出版、集会、结社、游行、示威六项并列的整体，不能只认其中一项。
  • 把"选举权"广义化：宪法上的选举权和被选举权特指选举/被选为人大代表；选班委、选业委会成员不在此列。A 恰恰因为指向国家权力机关才属于政治权利。
记忆锚点：政治权利两件套——选人（选举权和被选举权）+ 说话（六大政治自由）；人身自由、宗教信仰是隔壁的抽屉；"是前提"不等于"是本格"。

第 0 步：先立机制——必然性与偶然性的关系，三问的"总开关"

必然性是事物发展中确定不移的趋势，偶然性是可以这样、也可以那样的表现形式；必然性寓于偶然性之中，通过大量偶然表现出来，偶然背后隐藏着必然。落到"做事会出错"上：认识和实践要经过反复探索、难免出现失误，这是过程规律的必然；哪一次、以什么方式出错（用力过猛的一戳），则是偶然。这层关系立住了，三问的答案就顺着长出来——本题三问是一条"失败学"链条：失误为什么难免（客观规律）→ 为什么能化错为对（主观能动）→ 以后怎么办（方法论）。

第 1 步：问(1) 为什么"无论是大师还是普通人，失误和错误是难免的"

第 2 步：问(2) 为什么能把"险些造成舞台事故的错误"变为"经典之作"

机制：谬误与真理、失败与成功在一定条件下相互转化——条件不会自动出现，要靠人在尊重客观规律的基础上发挥主观能动性去创造。梅兰芳做齐了三件事：

第 3 步：问(3) 认识和实践活动中出现错误或失败该怎样对待和处理

  3. 总结经验教训，把失败变成认识深化的环节，在实践中检验和发展真理；

第 0 步：先立机制——"看似私事"为什么实为公事

交通环境由人、车、路构成，是典型的公共生活领域：公共生活的活动范围具有广泛性、交往对象具有复杂性、活动方式具有公开性和透明性——个人行为直接作用于素不相识的他人。所以斑马线上的"一脚油门"看似个人私事，实则关乎公共安全与共同利益。维护公共秩序有两个基本手段：道德（自律、软约束、靠自觉）与法律（他律、硬约束、靠强制）。这一机制立住，"既是……也是……"的句式就有了落点。

第 2 步：问(2) 为什么现在是"制造"上升为"创造"的时候了

  1. 处境自陈：材料直言中国"还处于产业链的低端"、被定义为"世界工厂"、"还只是产品的制造商"——加工组装环节技术含量与附加值低、缺少核心技术与自主品牌；
  2. 现实倒逼：仅靠低成本加工难以持续——要素成本上升、低成本优势递减；金融危机阴霾未散、贸易保护主义抬头，单纯依赖代工外销的空间收窄；
  3. 条件具备：60 年发展积累的产业基础、资金、人才与巨大市场，使创新升级成为可能；
  4. 出路方向：增强自主创新能力，掌握核心技术和自主品牌，提高产品技术含量和附加值；推动产业结构优化升级、转变经济发展方式，建设创新型国家——从"中国制造"走向"中国创造"。

"处于产业链低端""还只是制造商"低附加值环节 → 必须升级

易错点：每种丢分对应什么误解

  • (1)答成"中国产品质量好"的赞歌：丢掉"全球化相互依存、合作共赢"这个考点，答偏即不得分；
  • (2)只写"要加强创新"一句：漏掉核心技术、品牌、附加值、产业升级、发展方式转变等采分点，要点不全是主要丢分方式；
  • 脱离材料自陈的"低端/制造商"定位：答案悬空，没有"为什么是现在"的倒逼逻辑。
记忆锚点：制造 = 参与世界分工（借力成长）；创造 = 掌握核心环节（自立自强）。答(1)抓"依存共赢"，答(2)抓"低端倒逼 + 创新出路"。
