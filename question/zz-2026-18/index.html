规律与改造世界
2 分

答案：AD

本题讲解：从"马铃薯身世之谜"到基因育种的实践哲学

答案：AD。

第 0 步：先立机制——材料里藏着一条"规律 → 方案 → 实践"的完整链条

题干其实讲了一步接一步的三件事：

  1. 揭示规律：分析 128 份基因组，查明马铃薯约 40% 基因来自番茄祖先、60% 来自"薯先生"——客观存在的杂交联系被发现；
  2. 提出方案：以番茄为遗传底盘、导入块茎形成关键基因——依据规律设计实践方案；
  3. 改造世界：培育"地下结土豆、地上长番茄"的新型作物——把方案变成现实。

设问问"科学家能够利用基因技术进行新型作物的培育，是因为"——就是问第 2、3 步凭什么成立。答案自然指向两端：一头是规律（A），一头是实践能力（D）。

第 1 步：A 为什么对——正确活动的基础是"把握规律"

"对客观事物规律的把握是人们正确活动的基础。"基因杂交的规律是客观的，不以人是否发现为转移；但只有当团队把握了它（查明 40%/60% 的来源），才能设计出可行的育种路径。没有这一步，"培育新型作物"只是空想。这正是"尊重客观规律是正确发挥主观能动性的前提"的材料化表达。

第 2 步：B 为什么错——联系是客观的，不是意识"赋予"的

B 说"事物之间的联系通常都是人们主观意识所赋予的"。追问一句：番茄祖先与马铃薯之间的基因联系，是人赋予的吗？不是——它早在人类出现之前就客观存在了，科学家做的事是发现它、读懂它，而不是发明它。B 把"认识联系"偷换成"创造联系"，方向整个反了，是唯心主义的联系观。要补一句：人确实可以建立新的具体联系（人工杂交），但前提是遵循固有的客观联系，而非凭意识赋予。

第 3 步：C 为什么错——"必须先改造主观世界"不成立

C 说"改造客观世界的前提是人们必须先改造主观世界"。二者关系是在实践中相互促进、相互统一：改造客观世界的同时改造主观世界，主观世界的改造又反过来推动客观世界的改造。"必须先"三个字把关系变成先后排序——好像要先关起门完成思想改造才能动手实践；既不符合材料（团队是先动手做基因组研究），也颠倒了实践的基础地位。

第 4 步：D 为什么对——能力是实践的函数

"人类改造世界的能力随科学实践的发展而发展。"从传统杂交育种 → 基因组测序 → 人工设计育种路径，人类改造生物的能力每上一个台阶，背后都是科学实践的一次跃升。能力不是天生给定的，是在实践中长出来的——这正是材料"科学家提出一条新的育种路径"的哲学注脚。

第 5 步：对号入座

选项判断对号处
A 把握规律是正确活动的基础✅查明"混血"规律 → 才有育种路径
B 联系由主观意识赋予❌基因联系客观存在，人是"发现"不是"赋予"
C 先改造主观世界再改造客观世界❌二者在实践中相互促进，无"必须先"
D 改造能力随科学实践发展✅杂交 → 基因组 → 设计育种，能力随实践升级

→ 选 AD。

易错点

  • 误选 B：被"科学家提出新路径"的创造性叙述带偏，以为联系可以由人"赋予"。注意：人能建立新联系，但依据的是固有联系。
  • 误选 C：把"改造主观世界很重要"放大成"必须先改造"。多选题里"必须先""只有…才"这类绝对化排序词，多数是坑。
  • 漏选 D：只盯住"规律"一头，忘了设问的另一半——"能够利用基因技术"问的还有能力从哪来。
记忆锚点：规律是地基（A），实践长能力（D）；联系靠发现不靠赋予（B 反），主客观改造相互促进无先后（C 反）。
