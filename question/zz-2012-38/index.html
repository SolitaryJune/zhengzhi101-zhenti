国家形象与文化软实力
8 分

结合材料回答问题：
材料1
纽约曼哈顿的时报广场，被称为“世界的十字路口”。在胡锦涛主席2011年访美前夕，从1月17日起，一抹亮丽的“中国红”在这里明艳绽放——首部中国国家形象片《人物篇》在时报广场的大屏幕上持续滚动播放，路人纷纷驻足观看。
在这段时长60秒的宣传片中，不仅有袁隆平、杨利伟、姚明等各领域杰出代表，还有“轮椅天使”金晶、“抗震小英雄”林浩、“一辈子在献血”的郭明义等感动中国的普通百姓。他们都面带微笑，神色自信，于静默之间传递着中国的声音。
历史翻回到1904年5月的一天，在一家银行的外墙，贴出了时报广场上的第一张广告。100多年来，这里广告的每一次变幻刷新，都展示着时代的表情。可是在这当中，鲜有中国人的面孔和身影。百年沧桑，终以微笑定格。来到“世界的十字路口”，中国人自信、平和、友好。
摘编自人民网（2011年1月20日）
材料2
作为《人物篇》的姐妹篇，一部时长17分钟的中国国家形象片《角度篇》自2011年2月3日起将陆续在亚洲、欧美等地的多家电视台播出。《角度篇》分为“开放而有自信”、“发展而能共享”等8个部分，向世界展现了一个更丰富、多元的中国，其中70%以上的画面呈现的都是中国普通百姓的生活。值得一提的是，它没有回避中国目前存在的一些问题，农民工及其家属的生存现状在片中多次出现。这部国家形象片看似一些“视觉碎片”，但能够让世人从中读出一个比较真实、鲜活的当代中国。
摘编自新华网(2011年2月2日)
材料3
从2009年“中国制造世界合作”的广告片，到2011年的国家形象宣传片《人物篇》和《角度篇》，如此集中地向西方展示中国国家形象还是第一次。有评论认为，这几部短片展示了中国人民的勤劳智慧和精神风貌，每个人的笑容都那么阳光，让人油然而生到中国看看的愿望；还有人认为，这是“中国国际形象公关”的又一次主动出击，愈趋自信的中国主动向世界展示自己，中国开始步入“国家公关时代”；也有报道说，中国的宣传片是中国国家领导人出访之前的“盛大派对”，展示了中国的软实力。
摘编自人民网(2011年1月20日)
(1)分析“中国开始步入‘国家公关时代’”的原因。(4分)
(2)国家形象宣传对提升中国软实力有何作用?(4分)

答案

（1）中国与世界联系日益紧密，国际社会需要准确了解中国，中国也需要主动表达自身发展和主张、消除偏见，适应参与国际事务的要求。

（2）国家形象传播有助于展示人民生活、文化和价值追求，增强理解信任、吸引力及国际沟通能力；真实透明的表达与国内发展实践共同构成软实力基础。

本题讲解：国家形象片——"国家公关时代"的原因与软实力的作用

答题要点：第(1)问答"为什么此时主动出击"——经济全球化下中国与世界联系空前紧密，国际社会需要准确了解中国，中国也需要主动表达自身发展和主张、消除误解偏见，并已具备实力与自觉；第(2)问答"有什么用"——形象传播展示人民生活、文化和价值追求，增进理解信任与吸引力，真实透明的表达与国内发展实践共同构成软实力基础。

第 0 步：先立机制——"公关"一词的题眼

"国家公关"的题眼在主动二字。材料3说"如此集中地向西方展示中国国家形象还是第一次"——过去中国的形象多由他人描述（"他塑"），误读与偏见丛生；形象片意味着中国从"被描述"转向"自塑"。为什么要转？材料给了三重背景：时报广场百年"鲜有中国人的面孔和身影"（存在感与话语权不匹配）→ 2011 年中国已是世界第二大经济体（实力有了，形象与实力不匹配）→ 评论聚焦"软实力"（国际竞争已从硬实力延伸到吸引力、话语权的竞争）。第(1)问的"原因"就藏在这条链里；第(2)问看形象片传递了什么——自信微笑的普通人（《人物篇》）、《角度篇》70% 以上画面是普通百姓、不回避农民工生存现状——软实力的核心正是吸引力与认同感。

第 (1) 问：分析"中国开始步入国家公关时代"的原因（4 分）

  • 联系紧密是客观基础：经济全球化深入发展，中国的前途命运日益与世界紧密相连，中国的和平发展需要良好的国际舆论环境；
  • 国际社会"想了解"：中国的发展举世瞩目，国际社会需要准确、真实、立体地了解中国；
  • 中国"要表达"：主动介绍自己的发展道路与主张，消除误解与偏见，"自塑"而非任人"他塑"，是更好参与国际事务、承担大国责任的需要；
  • 能力与自觉已具备：综合国力增强，开展公共外交、塑造国家形象的条件成熟、意识自觉。

预判追问：为什么选在时报广场、领导人出访前夕？ 传播场景是答案的注脚：在"世界的十字路口"高频滚动、与高层外交节点呼应，说明这是主动设置议题、面向国际主流社会的公共外交行动——"公关"的实质是用现代传播手段参与国际话语竞争，而不是一般的商业广告投放。

第 (2) 问：国家形象宣传对提升中国软实力的作用（4 分）

作用机制材料对应
展示真实中国用人的故事传递生活、文化与价值追求，比抽象宣传更有说服力杰出代表 + 感动中国的普通百姓；《角度篇》70% 以上画面是普通百姓生活
增进理解信任不回避问题反而增强可信度，可信才有吸引力农民工生存现状多次出现，"读出一个比较真实、鲜活的当代中国"
提升吸引力与影响力自信平和的形象产生亲近感，提高国际吸引力、感召力与沟通能力"让人油然而生到中国看看的愿望"
改善舆论环境主动沟通为和平发展营造有利外部氛围"中国国际形象公关"的主动出击，展示软实力

收口：软实力 = 文化、价值观、国家形象等产生的吸引力与感召力（区别于经济、军事等硬实力）。形象片是软实力的传播放大器，但根基仍在国内发展实践——真实、透明的表达与实实在在的发展成就共同构成软实力，二者缺一不可。

易错点

  • 第(1)问答成"有钱了做广告"：要答"需要 + 必要 + 可能"多重原因（联系紧密、消除偏见、实力支撑），落点在话语权与公共外交，不能只谈经济。
  • 第(2)问把软实力说成经济军事实力：软实力特指文化、价值观、形象带来的吸引力、感召力，混淆硬实力直接跑题。
  • 忽略"不回避问题"这一细节：真实透明才可信——这是材料2埋给第(2)问的关键提示，漏掉会丢"增进信任"这一采分点。
记忆锚点：公关时代 = 联系紧密 + 想了解 + 要表达，从"他塑"到"自塑"；软实力作用 = 展示真实 → 增进信任 → 产生吸引 → 改善环境，根基在国内发展实践。
