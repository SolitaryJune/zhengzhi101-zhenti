zz-2014-06

人民代表大会制度
1 分

改革开放以来，人民代表大会制度建设和人民代表大会的工作得到不断推进。全国和地方各级人民代表大会的代表：

答案

答案：C

6

本题讲解：人大代表怎么选——改革开放以来的差额选举

答案：C（实行差额选举）。

第 0 步：先立机制——差额选举是什么、怎么来的

差额选举指候选人名额多于应选名额，让选民有挑选余地；与之相对的是等额选举（候选人数=应选人数，选谁都是「安排好的」）。选举制度改革的脉络：

时间变化
1953 年选举法基本实行等额选举
1979 年选举法直接选举扩大到县级，确立差额选举原则
此后多次修法差额比例、提名程序不断完善

改革开放以来人民代表大会制度的推进方向，就是把「等额」改成「差额」，扩大民主。所以「全国和地方各级人民代表大会的代表」选举实行的是差额选举。

第 1 步：干扰项各自错在哪

选项判断错因
A 按党派分配名额❌我国不搞多党竞争分席位；各政党、团体可以推荐候选人，但名额不是按党派分配的
B 按单位分配名额❌代表名额按地域/选举单位（行政区域、界别比例）统筹，不是「按单位」切块分配
D 等额选举❌这是 1953 年选举法的旧做法——改革开放以来的方向恰是「等额→差额」，与题干「不断推进」正好相反

第 2 步：预判追问——为什么 A、B 的说法「听起来也有点像」

确实存在「政党、人民团体推荐候选人」和「各界别有比例要求」的制度设计，容易让人觉得 A/B「沾边」。但「推荐渠道」≠「名额分配」：名额分配的依据是地域人口与选举单位结构，政党与界别只是提名主体和统筹考量。本题考的是代表产生的选举方式，落在 C 与 D 之间，而 C 是现行制度。

易错点

  • 误选 D（把「等额=稳妥」当现状）：这是 1953 年的旧制度；抓题干「改革开放以来……不断推进」，推进的方向就是更民主的差额选举。
  • 误选 A/B：被「政党推荐」「界别比例」的模糊印象带偏——记住名额分配看地域与选举单位，不看党派或单位。
记忆锚点：1953 等额 → 1979 起差额；各级人大代表一律差额选举产生；名额按地域统筹，不按党派、不按单位。
