zz-2023-08

党的自我革命
1 分

作为无产阶级政党，如何永远得到人民的拥护与支持，如何长期执政，是中国共产党必须回答好、解决好的问题。对于这一历史之问、时代之问，毛泽东在延安窑洞时给了一个答案,“只有让人民来监督政府，政府不松懈，只有人人起来负责，才不会人亡政息。”经过党十八大以来的不懈努力，我党找到了第二个答案，这就是

答案

答案：B

8

本题讲解：跳出历史周期率的两个答案——从人民监督到自我革命

答案：B（自我革命）。

第 0 步：先立机制——"两个答案"必须背成一张对照表

历史周期率之问（1945 年延安窑洞，黄炎培问毛泽东）的答案有两个，命题最爱考它们的配对与区分：

第一个答案第二个答案
时间1945 年延安窑洞党的十八大以来
提出毛泽东答黄炎培习近平
内容只有让人民来监督政府，政府才不敢松懈自我革命
路径外部监督（人民、民主）内部自觉（刀刃向内）

题干已把第一个答案（人民监督）念完，问"第二个答案"——直接查表：自我革命。二十大报告原文："经过不懈努力，党找到了自我革命这一跳出治乱兴衰历史周期率的第二个答案。"

第 1 步：预判追问——两个答案是什么关系？为什么 C 不是"答案"？

两个答案是结合关系，不是替代：外部监督（人民民主）保证党不敢松懈；自我革命（全面从严治党）保证党主动不腐不变质——一外一内，一起用才跳出"其兴也勃焉，其亡也忽焉"的循环。看清这个结构，就知道 C 为什么不对："把权力关进制度的笼子"是自我革命统领下的一项具体举措（制度反腐的路径之一），它回答"怎么做"；而题目问的是与"人民监督"并列的那个"答案"本身——一个是路径清单里的一条，一个是纲领性结论，层次不同。

第 2 步：逐项对号入座

选项判断定位
A 坚定理想❌党的精神层面的优势（理想信念），不在"两个答案"对照表里
B 自我革命✅二十大报告原文：跳出治乱兴衰历史周期率的第二个答案
C 把权力关进制度的笼子❌自我革命统领下的具体举措（路径之一），不是"答案"本身
D 增强忧患意识❌居安思危的态度要求，也不在对照表里

易错点：每个干扰项对应哪种误解

  • 误选 C（最高频）：知道"要管住权力"就选了"制度的笼子"。注意层次：C 是自我革命这棵树上的一条枝（怎么做），B 才是那个与"人民监督"并列的答案（是什么）。干扰项故意用"正确的话"答"别的层次的题"。
  • 误选 A / D：把党的其他优良要素（理想信念、忧患意识）混进来。它们都重要，但"两个答案"这张表里只有人民监督和自我革命——背表时就要成对背，别让邻近概念挤进表里。
记忆锚点：历史周期率两个答案＝人民监督（外·1945 延安窑洞）＋自我革命（内·十八大以来）；一外一内、结合使用；"举措/态度"是路径层，不是"答案"本身。
