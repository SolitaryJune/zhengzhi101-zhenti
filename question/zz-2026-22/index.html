社会主义文化建设

本题讲解：毛泽东谈音乐与中外文化关系的根本观点

答案：ACD。

第 0 步：先立机制——一段谈话里的"三条处理线"

1956 年毛泽东同音乐工作者对谈，表面谈音乐，实际谈的是中外文化关系怎么处理。把材料拆开，三条线一清二楚：

  1. "地球上有二十七亿人，如果唱一种曲子是不行的"——世界若只剩一种文化，等于文化上的单一化，此路不通；九部乐、十部乐中西域、高丽、印度音乐与本土音乐并存，是多样性的历史实例 → 尊重文化多样性（A）；
  2. "演外国音乐并没有使我们自己的音乐消亡了"＋"说中国民族的东西没有规律……是不对的"——外国音乐进来没冲垮民族音乐，说明"一概排斥"是关门主义；但民族的东西自有其规律，"全盘吸收"则取消自己的主体性 → 两个极端都错（C）；
  3. 谈话的落点：学外国不是为了变成外国，而是"洋为中用"——要创造出中国自己的、有独特民族风格的东西 → 学外国长处、创民族风格（D）。

第 1 步：A、C、D 各自对在哪里

A 尊重文化多样性："唱一种曲子不行"是对单一化的正面否定；隋唐宫廷乐里西域乐、高丽乐、印度乐与汉乐同台，本身就是"地球不只一种曲子"的史证。文化多样性是人类社会的基本特征，尊重它是处理中外关系的前提。

C 一概排斥或全盘吸收都错：材料用两个史实各堵一个极端——"演外国音乐没使我们消亡"堵住排斥论（开放不亡国），"中国民族的东西有规律"堵住取代论（外国的不必也不能全盘搬来）。这次谈话的精神正是：既不关门，也不照搬。

D 学外国长处、创造民族风格：这是谈话的核心落点。学习的目的性要讲清楚——"以我为主、为我所用"，消化外国长处后长出的仍是"中国自己的、有独特的民族风格的东西"。学是手段，创造是目的。

第 2 步：B 为什么不选——观点本身对，但"对不上号"

B"要有自己的文化自信"放在今天完全正确，为什么排除？两处不合：

  1. 答非所问：设问限定"阐明中外文化关系的根本观点"。A、C、D 都直接回答"如何对待外国文化"（怎么相处、怎么学、学了干什么）；B 说的是对自己文化的态度，没落在"中外关系"这个设问点上。
  2. 超语境："文化自信"是新时代提炼的表述，1956 年的谈话文本里没有这一概念（题目解析也特别提示"注意当时论述语境"）。把后来的话语倒贴回历史文本，是史论题里最隐蔽的干扰类型：观点正确 ≠ 与材料对应。

第 3 步：对号入座

选项判断材料对号处
A 要尊重文化多样性✅"唱一种曲子是不行的"；九部乐十部乐多元并存
B 要有自己的文化自信❌非"中外关系"设问点；新时代话语超 1956 语境
C 一概排斥/全盘吸收都错✅演外国音乐未消亡（堵排斥）；民族的东西有规律（堵取代）
D 学外国长处创民族风格✅谈话落点：创造中国自己的独特民族风格

→ 选 ACD。

易错点

  • 误选 B：觉得"文化自信永远正确"就顺手选上。多选题要盯设问：问的是"中外文化关系"的观点，B 答的是"对自己文化"的态度——观点对但答非所问，同样不选。
  • 漏选 C：材料只明说了"不必怕外国音乐"，"全盘吸收也错"要靠谈话整体精神补齐：学外国是为了创造自己的东西，照搬即取消主体性。
  • 漏选 A：注意力全落在"学外国"上，漏掉"二十七亿人唱一种曲子不行"这句对单一化的强表态——尊重多样性是谈话的第一层意思。
记忆锚点：中外文化三原则——多样要尊重（A）、两个极端都不能走（C）、学了为创造（D）；"观点本身对、但与设问和语境对不上"的选项照样排除（B 反）。
