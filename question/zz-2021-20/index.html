资本的技术构成与价值构成
2 分

某服装厂为了实现更高的盈利，将原本依靠人工进行生产的流水线改造成了完全依靠机器进行生产的流水线。与此同时，由于受经济危机的影响，该服装厂从市场上采购的布料等生产原料价格也出现了大幅度的下降。在这种情况下，该服装厂资本构成会发生变化的是

答案

答案：ACD

20

本题讲解：机器换人 + 原料降价——三张「面孔」谁在变

答案：ACD。

第 0 步：先立机制——同一比例的三种说法

题干问「资本构成会发生变化的是」，得先立起政治经济学看「生产资料 vs 劳动力」这一比例的三张面孔，再看两个事件各自动了谁：

构成定义看什么
技术构成生产资料数量与劳动力数量的比例厂房实物：几台机器配几个工人
价值构成不变资本 c 与可变资本 v 的比例账本金额：买设备原料的钱对买劳动力的钱
有机构成由技术构成决定并反映技术构成变化的价值构成桥梁：技术构成变，它跟着变

两条关键机制：①技术构成变化必然牵引价值构成（机器换人 → c 增 v 减）；②价值构成还能被价格独立撬动——原料降价使 c 缩水，厂房实物比例纹丝不动。一条边界：只有由技术构成变化引起的那部分价值构成变化才叫有机构成变化，纯价格因素引起的不算。

第 1 步：两个事件各自动了谁——数字演算

设改造前：设备原料合计 c = 80 万，50 名工人工资 v = 50 万（c:v = 8:5），厂房里 50 台机器配 50 名工人。

  • 事件一：人工流水线 → 全机器流水线。 改成 100 台机器配 10 名工人：实物比例大幅提高——技术构成变；账面上设备投入涨、工资支出缩（设 c = 120 万、v = 10 万，c:v = 12:1）——价值构成变；且这轮价值变化由技术构成变化引起——有机构成变。
  • 事件二：布料等原料价格大幅下降。 原料支出从 30 万降到 10 万（c:v 从 12:1 变为 8:1）：账本再次改写——价值构成又变；但机器与工人的实物比例没动——技术构成、有机构成不因此变，也不会被「抵消」。

三个概念合起来：C 技术构成（事件一）、D 价值构成（两个事件）、A 有机构成（事件一）都发生了变化。

第 2 步：排除 B

  • B 资本积累构成：❌ 政治经济学里查无此概念。资本积累指剩余价值资本化，是一个过程而非「构成」；凭空拼凑的名词是本题唯一的杜撰项。

易错点：每个干扰项对应哪种误解

  • 漏 D：只盯「机器换人」这件显眼事，没算「原料降价」——两件事一升一降，都在改写 c 与 v 的比例。
  • 漏 A：以为原料降价把 c 拉低，「有机构成变化」就被抵消——有机构成的变化来自事件一的技术构成，价格波动改不了这条因果链，更取消不了已发生的变化；题目问的是「变不变」，不是升降方向。
  • 误选 B：见「积累」二字眼熟就顺手勾上——不存在的名词永远不选。
记忆锚点：三构成口诀——技术看实物、价值看账本、有机是「技术说了算的那份账」；价格能单独撬动价值构成，但撬不动有机构成；「资本积累构成」查无此人。
