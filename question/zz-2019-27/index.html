井冈山革命根据地
2 分

1927年10月,毛泽东率领湘赣边界秋收起义的工农革命军，开始创建以宁冈为中心的井冈山农村革命根据地，走农村包围城市、武装夺取政权的革命新道路。毛泽东确定在井冈山建立根据地，是因为这个地区

多选题：点击切换选中，可多选；少选、错选均不得分。

答案

答案：ABCD

27

本题讲解：为什么是井冈山——红色政权选址的条件组落到一块具体的土地上

答案：ABCD。

第 0 步：先立时间线——选址是"打不动城市"之后的现实选择

把 1927 年这条轴立起来，选址决策才有语境：

时间事件对选址的意义
1927.9湘赣边界秋收起义，攻打长沙受挫强攻大城市这条路走不通
1927.9文家市决策转兵农村方向从"城市中心"转向"农村"
1927.9 底三湾改编（支部建在连上）部队完成整编，党指挥枪
1927.10引兵井冈山，以宁冈为中心创建根据地选址落地：农村包围城市的起点

第 1 步：再立机制——一块根据地"站得住"需要四个维度

红色政权要在敌强我弱的环境里长期存在，四个维度缺一不可：政治上要有群众基础、敌方统治要薄弱（进出的两头条件）；军事上要地形可守；经济上要养得起部队。井冈山恰好四条全占——题目问"是因为这个地区"如何，就是在考这组条件的落地。

第 2 步：A~D 对号入座

  • A 有较好的群众基础：大革命时期湘赣边界农民运动兴起、影响尚存，红军一到就有群众接应——政治维度之一。
  • B 地势险要且易守难攻：罗霄山脉中段山高林密，进可攻、退可守——弱小的红军需要地形保护，军事维度。
  • C 易于部队筹粮筹款：周围各县农产丰富、自给自足，能支撑长期驻留的军队供给——经济维度。
  • D 敌人的统治力量比较薄弱：地处湘赣两省交界、远离中心城市，是反动统治的缝隙地带——政治维度之二。

→ 四条齐备，选 ABCD。

第 3 步：预判追问——哪条最容易被漏？为什么偏偏不能漏 C？

考生容易只记"群众基础好 + 敌人弱"两条政治理由。但根据地不是打了游击就走，要养活军队、长期经营——再险要的地形、再好的群众，没有粮食和经费也守不住。而且恰恰不是越穷越好：太穷的地方养不起兵，选中的地区要农产丰富。C 是四条里唯一的"常识层"依据，也最容易因"偏僻穷困 = 革命根据地"的刻板印象被漏掉。

易错点

  • 漏选 C：把"偏僻穷困"当成根据地的特征——事实相反，根据地要能自给自足；这是对选址逻辑中"经济维度"的遗漏。
  • 漏选 B 或 D：只背"群众基础"一条——敌弱（缝隙地带）与地险（军事屏障）分别是政治、军事维度，少一条红色政权都难以长期立足。
记忆锚点：井冈山选址四条 = 群众基础（A）+ 地形险要（B）+ 筹粮筹款（C）+ 敌人薄弱（D）——政治、军事、经济三维度齐全，全选。
