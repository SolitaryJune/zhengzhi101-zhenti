zz-2014-31

爱国主义
2 分

中华民族的爱国主义优良传统源远流长，内涵极为丰富。下列诗句中反映爱国主义优良传统的有：

多选题：点击切换选中，可多选；少选、错选均不得分。

答案

答案：ABCD

31

本题讲解：四句诗一个魂——爱国主义优良传统的判诗标尺

答案：ABCD（全选）。

第 0 步：先立机制——判诗为什么不能靠"背名句"

这道题考的不是文学史，而是一次归类：把四句具体的诗，归进"爱国主义优良传统"的内涵清单里。教材给这份清单列的条目是——维护民族团结与祖国统一、抵御外侮捍卫民族尊严、忧国忧民以天下为己任、开发建设祖国等。

归类要有一杆标尺。这杆标尺不是"诗句写得悲还是壮"，而是：诗中的情感是否指向国家民族的命运。四句诗作者不同、朝代不同、境遇不同，恰好各自覆盖清单里的一个侧面——这正是命题人选这四句的原因。标尺在手，逐句对号。

第 1 步：逐句对号

诗句作者与背景情感指向什么对应的传统侧面
A 四万万人齐下泪，天涯何处是神州谭嗣同，甲午战败、列强瓜分之际悲的是山河破碎、国家存亡忧国忧民、以天下为己任
B 寄意寒星荃不察，我以我血荐轩辕鲁迅《自题小像》，青年立志誓把热血献给民族献身民族、捍卫民族尊严
C 位卑未敢忘忧国，事定犹须待阖棺陆游《病起书怀》，罢官闲居仍忧国地位卑微仍心系国事人人可为的家国担当
D 苟利国家生死以，岂因祸福避趋之林则徐，虎门销烟后遭贬赴戍国家利益置于个人祸福之上为国不计生死利害

四句全部落在标尺之内 → 全选。

第 2 步：预判两个"为什么"

  • 为什么 A 的"悲歌"也算爱国？ 诗句表面是泪与绝望，但泪因"神州"而落——悲恸的对象是国家命运，不是个人得失。痛感来自爱国，这是最深的一层感情。
  • 为什么 C 的"位卑"者也算主体？ 爱国主义从来不是"肉食者谋之"的专属品，陆游罢官后仍"不敢忘忧国"，恰恰说明爱国传统具有群众性——普通人的忧国之思同样是这个传统的组成部分。

易错点

  • 漏选 A（误判"太消极"）：把悲看成与爱国对立的情绪，没看出悲的对象是山河破碎——亡国之痛恰是忧国忧民的极端形态。
  • 漏选 C（误判"主体不够格"）：以为爱国大义须由显赫人物承担，忽略了传统的群众性一面。
  • 漏选 B（只知"血荐轩辕"是名句不知其义）：不清楚"轩辕"即指中华民族，热血所荐正是国家民族。
  • 漏选 D（觉得与"祸福避趋"相连像明哲保身）：其实诗句说的是"岂因祸福避趋之"——不因个人祸福而趋避，恰是国家利益至上的宣言。
记忆锚点：判诗只看一件事——情感是否指向国家民族的命运；四句四个侧面——忧国之泪（A）、荐血之誓（B）、位卑之忧（C）、生死之诺（D），无一例外，全选。
